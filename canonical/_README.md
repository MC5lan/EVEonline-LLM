# canonical/ — 重写语料

## 这是什么

`corpus/` 是**原始素材**：654 篇来自不同作者、不同年份、带 PDF 伤痕的文档。
`canonical/` 是**重写产物**：按主题重新组织、数值对齐 SDE、术语统一、去重后的权威版本。

两者并存，不互相替代：

| | corpus/ | canonical/ |
|---|---|---|
| 性质 | 素材，保留原貌与出处 | 结论，可直接用于训练与检索 |
| 数值 | 可能是 2018–2023 年的 | 对齐当前 SDE |
| 重复 | 同一主题多份并存 | 一主题一篇 |
| 冲突 | 原样保留 | 已裁决，或列入「存疑」 |

## 写作原则

1. **数值优先取 SDE**。SDE 查不到的（经验值、收益、操作技巧）必须标注来源与年份。
2. **冲突以 SDE 为准**；SDE 也无法裁决的（如配装思路、走位），写进「存疑」或注明「文档一致但未核实」。
3. **术语用官方中文名 + 社区别名**，并在文末给对照表。
4. **不写废话**。没有信息量的过渡句一律删掉——训练语料里每一句都在消耗模型容量。
5. **单篇控制在 800–2000 字**。超过就拆主题，因为检索块是 500 字量级。

## 文件头字段

```yaml
id: canon-abyss-00          # canon-<域>-<序号>
title: 深渊总览
domain: 05_生产与经济
subdomain: 05.6_深渊
type: canonical
status: 初稿 | 已核 | 存疑
sde_build: 3662168 / 2026-10-30
verified: 2026-11-01
confidence: 高（机制）／中（收益）
sources: 后篇深渊攻略、深渊教学入门…
```

## 索引

canonical 文档的 `type: canonical` 会被索引识别，`tier` 设为「权威」（高于攻略），
检索时优先返回。原始素材仍然保留，用于溯源与补细节。
