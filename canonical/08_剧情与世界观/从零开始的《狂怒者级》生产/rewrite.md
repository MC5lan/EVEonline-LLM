# 从零开始的《狂怒者级》生产

PS：“集会”分为大、小集会，各自对应8、5波怪，最后一波一般会有2~4只NPC，在打死其中“关键NPC”后有几率弹出远征“古斯塔斯复兴营地”，即“6-10”，可130M出售给军团或联盟成员，此项为前期主要主要收益。（最后一波怪有几率出现前缀为“恐惧古斯塔斯”的NPC，其死亡后，残骸中有几率出现左上角带有绿色图标的“势力装备”，此装备一定要拾取，其他残骸的装备没有太高价值。）

## 要点

- A+左击目标：朝向目标W+左击目标：环绕目标Q+左击空间位置X2：首次为确定距离，其次为确定角度
- 危险预警设置（提示关注战舰） 1：左击电容盘右下角三条杠，选择“设置舰船损伤预警”2：护盾、装甲警报阈值设置70%~80%之间；结构拉满，电容警报阈值设置20%~30%之间
- 旗舰远征：古斯塔斯旗舰集结地，3000w旗舰建筑远征：古斯塔斯加强护盾母星，3000wBOSS远征：古斯塔斯占据的矿场，7小时时限（建议自己打） 官员远征：古斯塔斯攻击地点，4小时时限，50ｅ左右4/10 ：古斯塔斯侦查哨站5/10 ：古斯塔迷幻剂供应点6/10：古斯塔斯复兴营地，1.3ｅ7/10：古斯塔斯军用复合体，一般没人要8/10：皮特管教所，一般没人要9/10：恐惧古斯塔斯舰队集结地，5000w10/10：迷魂阵，1.8ｅ
