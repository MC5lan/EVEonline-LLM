## 十一、易混淆项

| 易混淆点 | 说明 |
|---------|------|
| NC vs 北萌 | NC = Northern Coalition. (欧服)，北萌 = 北方联盟 (国服已灭灯)，完全不同组织 |
| D.C | Dracarys. 的 ticker，注意末尾有点，不是 Washington DC |
| -10.0 vs REKTD | -10.0 = Pandemic Legion (PL)，REKTD = Pandemic Horde (PH)，两个不同联盟 |
| INIT. | The Initiative. 的 ticker，末尾有点 |
| B B C | Snuffed Out 的 ticker，不是英国广播公司 |
| STUGH | Rote Kapelle 的 ticker，不是 Rote |
| 5IGMA | Sigma Grindset 的 ticker，不是 SIGMA |
