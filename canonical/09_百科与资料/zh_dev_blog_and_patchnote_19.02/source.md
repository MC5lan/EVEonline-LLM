-----23/3===== 機制 =====
 *遠距離克隆有以下數項調整：
 *容許玩家在同一位置安裝複數遠距離克隆
 *進行遠距離克隆或安裝新遠距離克隆不會再覆蓋目的地現存克隆
 *人物表單中的遠距離克隆的 ”Install Clone” 欄目將常設顯示
 *”Install Clone” 欄目將顯示目前位置已安裝遠距離克隆的數目
 *進行遠距離克隆將不會再關閉玩家倉庫視窗

===== 裝備 =====
 *自身艦船裝備了 Burst Jammer（ECM 脈衝波）後, 將停用自己艦船免疫非鎖定型攔截能力
 *Target Breaker Amplification 技能重命名爲 Signature Masking
 *每級增加 Signature Radius Suppressor 裝備啟用時間 5%
 *重新設定 Target Spectrum Breaker 裝備，改爲爲艦船被動提供信號半徑減成，在主動啟用時短暫時間內再大幅度減少信號半徑
 *被動信號半徑減少：10%
 *主動信號半徑減少：70%
 *有效時間：12秒
 *重啟延遲：2.5分鐘
 *啟用電容需求：600
 *CPU：50 tf
 *PWG：1 MW
 *最多裝備數量：1
 *容許裝備艦船：戰列艦，掠奪艦，黑隱特勤艦

===== 蟲洞 =====
 *中型蟲洞的最大單次通過質量由 2000萬 上調至 6200萬
 *大型蟲洞的最大單次通過質量由 3億 上調至 3.75億
 *超大型蟲洞的最大單次通過質量由 13.5億/18億 上調至 20億
 *減少高級別未知星系之間漫遊蟲洞的產生機率 50%

-----16/3===== UI =====
 *General Setting 中加入選項 : Inventory Badging, 開關倉庫新增物品標記功能(紅點)

-----12/3===== 探索 =====
 *爲新伊甸各地方加入位標, 讓玩家們能更容易發現這些地點
 *去世玩家紀念碑
 *SOE Project Discovery 第一階段紀念碑
 *探險家 Katia Sae 碉像
 *Pashanai 紀念碑

-----11/3===== 音效 =====
 *調整跳躍時的音樂音量, 由 -96dB 調整至 -6dB

===== 活動 =====
 *Federation Grand Prix : 即日至 23/3
 *活動需要玩家到訪新伊甸中各地標, 有三個地點, 終點是 Luminaire
 *第一次行訪活動路線並沒有時間限制, 第一次完成所有三條路線後將解鎖所有活動獎勵, 包括 Luminaire Zenith 以及能提升艦船速度及躍遷速度的新型增效劑
 *第一次完成活動路線後, 玩家可以嘗試競速挑戰
 *三條路線的完成速度最快的頭 10 位玩家的名字將會被記錄於 Luminaire 的活動位標上
 *注意 : Federation Grand Prix 路線將包括很多低安全等級星系及一些 0.0 安全等級星系。CCP 建議玩家只駕駛一些能承擔損失風險的艦船。玩家在完成路線時可能需要注意躍遷路線安全以及迴避潛在風險
 *玩家可以透過每日登錄遊戲獲得 Federation Grand Prix 每日登錄獎勵, 包括 Luminaire Zenith SKIN, 提升速度的增效劑, 免費的四天時效截擊艦專家系統
 *12/3 - 16/3 亦會舉辦特殊的 1v1 截擊艦深淵競賽, 是次競賽將會提升參賽者 100% 艦船速度

===== 圖像 =====
 *所有艦船及建築上的炮台均在其加載至場景時一同加載顯示

===== 艦隊陣型 =====
 *加入新功能 : 艦隊陣型
 *要使用艦隊陣型, 玩家需要學習新技能 Fleet Formations
 *艦隊陣型選單能夠在艦隊視窗中的新分頁查看
 *艦隊躍遷所使用的預設陣型會和現在的一樣
 *玩家可以在 Plane, Wall, Sphere, Arrow, 及 Relative 陣型中選擇其中之一
 *可分別設定 Fleet, Wing, 及 Squad 的陣型

===== 探索 =====
 *在 Sarum Prime 星系中的 "Mekhios Graveyard" 位標有重大更新
 *另外亦添加了幾個位標地點
 *著名玩家 Chribba 的紀念碑可於 Amarr-艾瑪 星系中找到
 *紀念皇帝 Doriam II 的紀念碑可於 Kor-Azor-柯埃佐 星系中找到
 *Federation Grand Prix 終點線可於 Luminaire-泛光之源 中找到, 這亦代表於 11/3 舉行的 YC123 Federation Grand Prix 起跑線
 *紀念聯盟盃賽事的紀念碑可於 Manarq-馬納克 星系中找到
 *紀念玩家們爲 Project Discovery 的紀念碑可於 Pakhshi-帕克什 星系中找到

 *p.s. 這是 CCP 翻新及在新伊甸園中添加地標計劃的第一批項目, 以反映玩家歷史和 NPC 歷史。多謝各玩家的建議及反饋。

===== 裝備及改裝件 =====
 *修改 "Standup L-Set EW Expert System I 及 II" 名字爲 "Standup L-Set EW Command System I and II"
 *加入新型部署式裝備 : Mobile Cynosural Beacon (移動式誘導力場信標)
 *不容許使用 : 蟲洞, Pochven, 深淵
 *星系安全等級限制 : 0.5 以下
 *部署時間 : 2分鐘
 *有效時間 : 1小時
 *體積 : 400
 *技能需求 : Anchoring (空間定錨) III
 *藍圖可以於提供移動式裝置的 NPC空間站找到

 *Mobile Cynosural Beacon 在部署後將會與艦隊相互綁定。部署完成後, 它將會如一個一般的誘導力場直至到達有效時間, 而不會因艦隊組成或部署玩家更改而有所改變。

===== 任務及 NPC =====
 *Triglavian Werposts 及 EDENCOM GunStars 據點重新加入 NPC 增緩部隊

===== 技能 =====
 *加入新技能以使用艦隊陣型
 *Fleet Formations
 *Fleet Coordination

===== 專家系統 =====

專家系統是一種受限人工智能系統以幫助玩家在租用期內使用某一系列技能
 *人物表單中加入一個新的專家系統分頁
 *玩家可以在此分頁瀏覽管理使用各種專家系統
 *專家系統兌換時會同時套用至該角色
 *啟用中的專家系統即使在玩家克隆死亡或更換克隆時仍然有效
 *專家系統的租用時間最長可延長至 30天
 *在以下位置會看見可選用專家系統的建議提示
 *艦船樹狀表
 *正準備出站的艦船的艦船信息
 *艦船的技能需求
 *市場上的艦船信息
 *艦船浮動提示

 *專家系統是一個幫助新玩家參與初階活動的系統。目前只能透過 EVE 商城購入, 但某些專家系統會作爲每日登錄獎勵贈送給玩家。

===== UI =====
 *在 Selected Item window 視窗中亦會顯示該建築的增強時間
 *艦隊廣播按鈕加入快捷鍵操作
 *總覽分頁的浮動提示加入顯示正在使用的總覽設定
 *等級 4 和 5的代理人加入 Ω 需求的邊框
 *加入取消緊急躍遷的選項
 *在艦船啟動躍遷失敗時, 艦船將會繼續保持其朝向及其速度
