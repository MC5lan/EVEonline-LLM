# 强暴

=====强暴=====''强暴''是指在高安地区在没有击杀权(无高安宣战,被击杀玩家无嫌犯计时器)的情况下强行击杀其他玩家的行为.

这种行为本身会导致统合部介入并击杀强暴者的船只.但是由于统合部的反应需要一定的时间,这会给强暴者时间来击毁自己的目标.一般而言,强暴的目标通常是高价值船只.

====常见强暴用船====促进级与长尾鲛级: 便宜且技能需求很低

塔洛斯级与娜迦级: 相对比较昂贵且技能需求稍高,火力很强

龙卷风级: 相对比较昂贵且技能需求稍高,但龙卷风级拥有很高的单发伤害

此外一个完整的强暴团伙可能还会有拾取受害者残骸的工业舰或货舰, 通过撞击使得受害者货舰无法起跳的船与用来吸引统合部注意的新手船。

====强暴的原理=======星系安等与统合部反应时间===

所有星系都存在一个安全等级，它在游戏屏幕的左上方，星系名称的右边。高安地区指的是安等在0.5到1.0之间（包括0.5与1.0）的星系。星系的安等越高，统合部反应的时间就越快。

尽管CCP并没有官方确认过，但普遍认为星系安等与统合部反应时间可以归纳为下表，但在实际游戏中，统合部警察生成的时间会因为服务器延迟等原因而有所变化。

^ 星系安等 ^ 统合部基础反应时间 ^
| 0.5 | 19秒 |
| 0.6 | 14秒 |
| 0.7 | 10秒 |
| 0.8 | 7秒 |
| 0.9或1.0 | 6秒 |

此外假如统合部警察在生成以后且在总览范围以内，那么对于第二次犯罪行为它们的反应时间会额外延长5到6秒。当它们对犯罪行为作出反应时，统合部警察需要大约2秒锁定目标并会在15秒内摧毁犯罪船只。

===强暴船的DPS===以最常见的促进级为例。
一条强暴用促进级的DPS应该在280左右。按照之前的数据，在干扰完统合部警察后，在0.5的星系，强暴者至少有19(统合部基础反应时间)+5(统合部被干扰后的额外反应时间)+2（锁定时间）= 26秒。在这段时间里，这条促进级可以打出的伤害是7280，足以击毁一条T1工业舰，而10条促进级则足以击毁一条偷运舰。

====强暴的战术====

通常而言，强暴者会有以下几个战术：
===货柜扫描===

使用一条带着货柜扫描仪的船在附近的高安贸易中心或者沿着贸易路线来寻找潜在目标，从而确定强暴舰队的船只类型与数量。这通常发生在比较繁忙的贸易路线，比如吉他到艾玛的路线===起跳干扰===

这通常是针对货舰，因为这类船只的起跳时间比较长，所以强暴者会利用一些高速，质量大且抗性强的船来撞击货舰使得它无法进入起跳状态。这样一来即起到反跳的效果又可以不受到统合部介入的影响。
===新手船攻击===

如果目标货舰选择原地下线来避免干扰，那么强暴者会尝试用新手船攻击目标从而令对方获得pvp计时。又或者目标不是货舰而是有高价值装备的其它舰船，那么强暴者会尝试用新手船反跳住目标以保证强暴舰队到场时目标还没有逃脱。
===吸引统合部注意力===

尽管统合部警察拥有极快的跃迁速度，但它们仍然需要时间赶到犯罪现场。因此一个常见的吸引统合部注意力的方式是用新手船在星系的某处进行犯罪行为，比如突然对过路船只进行攻击，从而给真正的强暴舰队额外时间来进行强暴。

====主要强暴地点====

以下这些地点是最常有强暴者出没的星系：

犹达玛（Uedama）：位于吉他到多迪谢路线的必经星系。

米亚尔加（Niarja）:位于吉他到艾玛路线的星系，同时吉他到赫克路线也会经过这里

巴勒（Balle）：位于艾玛到赫克路线的重要星系，同时也是吉他到赫克路线的关键点

此外，在以上星系附近的0.5与0.6安等的星系，比如希瓦拉（Sivala）等也会成为强暴地点。
