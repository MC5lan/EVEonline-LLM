# zh_rules_pve_ratting

- 对于主权区异常刷怪，严格遵守 start#生产活动范围 划定的区域限制。
 - 禁止在''4-HWWF'' 使用旗舰生产。
- 例外情况：经联盟值守舰队指挥同意，为剧本需要可以在4-HWWF使用旗舰生产。
 - 常规舰船或旗舰被抓求救的，应加入联盟值守舰队并在 Mumble 战区频道内提供准确信息。
 - 禁止泰坦、超旗挂靠建筑进入AFK状态，离开电脑时务必进站停靠或安全下线。
 - 禁止使用

## 要点

- ===== 规则主体 =====  - 取消所有的异常刷怪报点，除AOE优先避难异常以外先到先得,不再需要在聊天频道中报告异常情况。不再使用刷怪频道，请使用本地或其他方式进行沟通。  - AOE享有避难异常的最高优先级，本地出现其他刷怪常规应让出避难异常点；若本地出现两支及以上AOE舰队，鼓励私聊频道报点，避免撞车  - AOE生产过程中，默认补刀导电等小船为生产队一员，有且仅限一条  - AOE优先级报点条件，最少四个AOE组成AOE生产队，生产队外可以包含一个非AOE辅助船  - 狂怒等极慢效率船只保留作为技能不够时的补充，禁止多开拖慢整体异常刷新速度。  - 若出现本地多人生产或星系资源不足问题，则依照联盟推荐模式生产，即YST刷老巢、掠夺刷圣坛、AOE刷避难  - 任何阻碍他人生产的行为，一经联盟仲裁确认，先ban后踢  - 报点频道已退役  - 警告：当你生产期间，遇到明显来自盟友的攻击伤害，请优先撤离现场，以防误伤，如果发现本可离场避免误伤情况下，选择保持现状，不予受理纠纷仲裁，遇到问题请及时联系总监，走仲裁流程
- ===== 沟通案例说明如下 ========= 有效沟通： ====<code>Noraus：AOE +1, 小避难优先（rock haven priority） Tang：1</code>
- ==== 反面案例： ====<code>Tang：AOE+1, 小避难优先（rock haven priority） Noraus：我是YST，我偏不让最后YST跳进AOE被炸死，这种案例不经理赔</code>
