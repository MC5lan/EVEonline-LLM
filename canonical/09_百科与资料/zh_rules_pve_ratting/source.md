# zh_rules_pve_ratting

====== 刷怪规定 ======

===== 基本要求 =====

 - 对于主权区异常刷怪，严格遵守 start#生产活动范围 划定的区域限制。
 - 禁止在''4-HWWF'' 使用旗舰生产。
- 例外情况：经联盟值守舰队指挥同意，为剧本需要可以在4-HWWF使用旗舰生产。
 - 常规舰船或旗舰被抓求救的，应加入联盟值守舰队并在 Mumble 战区频道内提供准确信息。
 - 禁止泰坦、超旗挂靠建筑进入AFK状态，离开电脑时务必进站停靠或安全下线。
 - 禁止使用无畏刷异常空间。
 - 不建议使用超旗刷异常空间（CN禁止使用超旗刷异常空间）。
 - 允许使用超旗刷旗舰信标，应当加入兴趣小组''超旗伞下作业''；使用大鱼刷开旗舰信标的，信标应当部署在有矿石的星带中。
 - 超旗生产配装、语音及区域具体要求，请查看 crab。

===== 异常空间（战斗地点） =====

===== 规则主体 =====
 - 取消所有的异常刷怪报点，除AOE优先避难异常以外先到先得,不再需要在聊天频道中报告异常情况。不再使用刷怪频道，请使用本地或其他方式进行沟通。
 - AOE享有避难异常的最高优先级，本地出现其他刷怪常规应让出避难异常点；若本地出现两支及以上AOE舰队，鼓励私聊频道报点，避免撞车
 - AOE生产过程中，默认补刀导电等小船为生产队一员，有且仅限一条
 - AOE优先级报点条件，最少四个AOE组成AOE生产队，生产队外可以包含一个非AOE辅助船
 - 狂怒等极慢效率船只保留作为技能不够时的补充，禁止多开拖慢整体异常刷新速度。
 - 若出现本地多人生产或星系资源不足问题，则依照联盟推荐模式生产，即YST刷老巢、掠夺刷圣坛、AOE刷避难
 - 任何阻碍他人生产的行为，一经联盟仲裁确认，先ban后踢
 - 报点频道已退役
 - 警告：当你生产期间，遇到明显来自盟友的攻击伤害，请优先撤离现场，以防误伤，如果发现本可离场避免误伤情况下，选择保持现状，不予受理纠纷仲裁，遇到问题请及时联系总监，走仲裁流程

Noruas：不可以遇到以上情况，带上沟通和游戏截图，一经查实按第五条处理</code>

===== PVE SRP =====
 - AOE造成的伤亡，除非故意，否则无责，即不需要赔付
 - 任何由于违规行为造成的损失，如无特殊情况，应由违规者承担SRP
 - 若遇争端造成的损失，私下协商无果，请联系联盟仲裁官员
