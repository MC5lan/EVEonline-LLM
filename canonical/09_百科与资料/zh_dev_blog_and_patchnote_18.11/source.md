===== 遊戲機制 =====Dynamic Bounties System - 動態賞金系統 (DBS) 調整:
 *平衡狀態系數由 115% 上調至 135%
 *最大賞金系數由 150% 上調至 180%
 *星系賞金系數若在平衡狀態以下, 系數的自然回復速度上調, 使星系能更快地自然回復至平衡狀態系數

Encounter Surveillance System - 事件監測裝置 (ESS) 調整:
 *破譯主帳戶所需時間由 5分鐘 上調至 6分30秒
 *主帳戶自動支付間隔由 3小時 下調至 2小時
 *ESS 限制隱形區域由 半徑75km 上調至 150km, 其餘限制的距離不變。

===== 遊戲系統 =====

動態賞金系統
 *在 0.0 星系 (高安/低安/蟲洞/三神裔星系除外), 星系活躍度將會影響賞金的支付額度
 *賞金支付系數可透過星圖查看, 玩家可以找尋高價值星系前往獵殺海盜
 *賞金支付系數將會持續按星系內的活動而調整 : 刷怪活動會使系數下降, 而玩家被擊毀則會使系數上升
 *更詳細說明請參閱 : concord_introduces_the_dynamic_bounty_system

Encounter Surveillance System - ESS (事件監測裝置)
 *ESS 將強制部署於所有可佔領主權 0.0 星系
 *ESS 的部署地點是全星系公開的，並且需要通過設立了艦船級別限制的加速軌道才能前往。
 *ESS 將會自動支付其收繳的額外賞金, 玩家不需要親自去收取賞金。
 *ESS 有一系列特殊訪問限制, 此 ESS 規則將會影響其半徑 75km 內的艦船, 包括:
 *不能躍遷
 *不能使用微型跳躍引擎
 *不能使用微型躍遷引擎
 *不能隱形
 *不能使用誘導力場
 *不能激活纖維
 *不能部署物品
 *一部份的刷怪賞金收入將會被 ESS 收繳而非直接支付到玩家錢包。收繳的賞金將分開兩份儲存:
 *主要 : 大部份收繳的賞金都會儲存在這位置, 並且每 3 小時自動支付給回玩家, 但期間可隨時被入侵者提走。
 *儲備區 : 一小部份的賞金會儲存在這位置, 將會一直累積直至有玩家前往提走。要提走此部分的賞金, 玩家需要消耗一個特殊鎖匙才能提取。此鎖匙將會在日後透過遊戲內途徑推出。
 *更詳細說明請參閱 : encounter_surveillance_system_update

===== 植入體 =====
 *加入新型植入體 : Nanoheuristic Clone Mapper (納米觸發式克隆映射裝置)
 *玩家需要在太空倉被擊毀前植入此新型植入體, 以便使用戰術克隆功能
 *此植入體的有效時間爲 6小時 (能透過 Biology 延長有效時間), 在玩家被擊殺後仍然有效
 *海軍 LP 商店可以獲得此植入體藍圖

===== 忠誠點商店 =====
 *統合部 LP 商店的 Agency 增效劑 的兌換需求 三神裔調查數據庫(Triglavian Survey Database) 增加 8

===== 裝備 =====Tactical Capsuleer Recloner (戰術克隆重製體)
 *一款新型裝備, 以供艦隊成員被擊殺後直接於太空中重新
 *只供超級航空母艦裝備
 *按不同超級航空母艦而使用不同燃料塊, 每一次戰術克隆重生消耗 10 個燃料塊。系統會從艦隊倉庫及貨櫃倉內提取燃料塊使用。
 *飛龍-Wyvern: 氮燃料塊(Nitrogen Fuel Block)
 *冥府-Hel: 氫燃料塊(Hydrogen Fuel Block)
 *萬古-Aeon, 歸魂-Revenant: 氦燃料塊(Helium Fuel Block)
 *夜神-Nyx, 仇恨-Vendetta: 氧燃料塊(Oxygen Fuel Block)
 *玩家可以從提供 克隆艙(Clone Vat Bay) 藍圖相同的空間站獲得此新型裝備的藍圖

===== 遊戲機制 =====太空重生
 *太空戰術重生容許艦隊成員在太空倉被擊毀時直至於太空中重生, 而不再是在空間站內重生。
 *太空戰術重生需要玩家預先植入 Nanoheuristic Clone Mapper 植入體, 並且同艦隊的超級航空母艦裝配有正在運作的 Tactical Capsuleer Recloner 裝備。
 *在太空倉被擊毀後, 玩家將會自動在同星系中最近距離的 Tactical Capsuleer Recloner 重生駕駛太空倉重生。重生後會有 60 秒的無敵時間。
 *艦隊視窗新增一個 "Active Recloners" 分頁, 以顯示所有正在提供戰術克隆功能的設施。
