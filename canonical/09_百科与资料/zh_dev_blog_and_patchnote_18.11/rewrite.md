## EVE Online 18.11 版本更新總結

<image shape="circle">作者: Rabbit P MuraSaki Siki</image>\\官网公告链接: Patch Notes For 18.11 Release \\论坛讨论帖: </jumbotron> (1/12)

## 遊戲機制Dynamic Bounties System - 動態賞金系統 (DBS) 調整:

*平衡狀態系數由 115% 上調至 135% *最大賞金系數由 150% 上調至 180% *星系賞金系數若在平衡狀態以下, 系數的自然回復速度上調, 使星系能更快地自然回復至平衡狀態系數 Encounter Surveillance System - 事件監測裝置 (ESS) 調整: *破譯主帳戶所需時間由 5分鐘 上調至 6分30秒 *主帳戶自動支付間隔由 3小時 下調至 2小時 *ESS 限制隱形區域由 半徑75km 上調至 150km, 其餘限制的距離不變。 ----- -----

## 平衡調整

*Wyvern (飛龍級) 和 Aeon (萬古級) 艦載機傷害加成增加至 每級 +7.5% *重型艦載機 HP 量 +10% *輕型艦載機 飛行速度 -10% *輕型艦載機 信號半徑 +10% *超級航空母艦艦船維護倉庫容量 由 2.5m 增加至 5m *所有超大型魚雷: *爆炸速度 : +20% *飛行速度 : +20% *傷害 : +10% *所有其他魚雷: *爆炸半徑 : -10% *爆炸速度 : +10% *飛行速度 : +20% *最大飛行時間 : +20% *魚雷發射器: *CPU 及 能量柵格用量 

## 伺服器

*改善隨時間傷害型超級武器的穩定度, 使之在高伺服器負載的情況下能更可靠地發揮全部傷害

## 活動

*慶祝 Jita 4-4 擴建工程的完工

## 遊戲系統

動態賞金系統 *在 0.0 星系 (高安/低安/蟲洞/三神裔星系除外), 星系活躍度將會影響賞金的支付額度 *賞金支付系數可透過星圖查看, 玩家可以找尋高價值星系前往獵殺海盜 *賞金支付系數將會持續按星系內的活動而調整 : 刷怪活動會使系數下降, 而玩家被擊毀則會使系數上升 *更詳細說明請參閱 : concord_introduces_the_dynamic_bounty_system Encounter Surveillance System - ESS (事件監測裝置) *ESS 將強制部署於所有可佔領主權 0

## 圖像

*Jita 超大型空間站落成。 *渲染後期處理將會套用在各 3D 預覽視窗, 例如艦船裝備頁面

## 玩法

*玩家可以在太空中領取每日登入增效劑

## 植入體

*加入新型植入體 : Nanoheuristic Clone Mapper (納米觸發式克隆映射裝置) *玩家需要在太空倉被擊毀前植入此新型植入體, 以便使用戰術克隆功能 *此植入體的有效時間爲 6小時 (能透過 Biology 延長有效時間), 在玩家被擊殺後仍然有效 *海軍 LP 商店可以獲得此植入體藍圖

## 忠誠點商店

*統合部 LP 商店的 Agency 增效劑 的兌換需求 三神裔調查數據庫(Triglavian Survey Database) 增加 8

## 裝備Tactical Capsuleer Recloner (戰術克隆重製體)

*一款新型裝備, 以供艦隊成員被擊殺後直接於太空中重新 *只供超級航空母艦裝備 *按不同超級航空母艦而使用不同燃料塊, 每一次戰術克隆重生消耗 10 個燃料塊。系統會從艦隊倉庫及貨櫃倉內提取燃料塊使用。 *飛龍-Wyvern: 氮燃料塊(Nitrogen Fuel Block) *冥府-Hel: 氫燃料塊(Hydrogen Fuel Block) *萬古-Aeon, 歸魂-Revenant: 氦燃料塊(Helium Fuel Block) *夜神-Nyx, 仇恨-Vendetta: 氧燃料塊(Oxygen Fuel

## 遊戲機制太空重生

*太空戰術重生容許艦隊成員在太空倉被擊毀時直至於太空中重生, 而不再是在空間站內重生。 *太空戰術重生需要玩家預先植入 Nanoheuristic Clone Mapper 植入體, 並且同艦隊的超級航空母艦裝配有正在運作的 Tactical Capsuleer Recloner 裝備。 *在太空倉被擊毀後, 玩家將會自動在同星系中最近距離的 Tactical Capsuleer Recloner 重生駕駛太空倉重生。重生後會有 60 秒的無敵時間。 *艦隊視窗新增一個 "Active Recloners" 分頁,

## 技能

*移除 三神裔 忠誠點商店中 Disintegrator Specialization （分解者專業研究）技能兌換 *深淵死亡空間中加入 Disintegrator Specialization（分解者專業研究）技能書掉落

## UI

*重新調整人物表單的克隆頁面 *玩家可以取消進行中的目標鎖定 *炮台及發射器信息視窗中加入顯示其對炮台/發射位的要求 *在關閉已堆疊視窗時加入確認提示 *若玩家於太空中仍然有操控中的無人機, 在其躍遷離開時加入警告提示 *在遠距離克隆收費是 0 時, 不再彈出支付金額提示
