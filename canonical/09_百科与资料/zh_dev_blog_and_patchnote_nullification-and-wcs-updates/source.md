--------

====== 泡泡免疫 & 躍遷穩定 調整 ======

-----\\原文鏈接: The Great Escape

</jumbotron>

大家好,

在接下來的 The Great Escape 更新中, 會有涉及 非鎖定型躍遷干擾 (免疫泡泡) 及 躍遷穩定核心 的調整, 想收集玩家們的意見。

-----

<fs x-large>大綱</fs>

非鎖定型躍遷干擾 (免疫泡泡) 能力 及 躍遷核心穩定 將會調整爲有長冷卻時間的主動啟用裝備, 這將成爲強力的逃離手段。

-----

<fs large>Interdiction nullification (攔截免疫)</fs>

以下艦船將可以使用這新型攔截免疫裝備
 *Interceptors (截擊艦)
 *Blockade Runners (偷運艦)
 *Covert Ops Frigates (隱形特勤艦)
 *Deep Space Transports (強運艦)
 *Luxury Yachts (奢華游艇)
 *Strategic Cruisers (戰略巡洋艦)
 *Tech I and Faction Frigates (Tech I 及 勢力 護衛艦)
 *Stealth Bombers (隠形轟炸艦)

而 Fleet Interceptors (艦隊截擊艦), Luxury Yachts(奢華游艇), 及 Tech III 推進子系統均會獲得攔截免疫裝備的啟用時間及冷卻時間加成。

過去專精於攔截免疫的艦船會有對此裝備更高的加成, 使他們成爲此使用裝備上更具吸引力的選擇:
 *截擊艦, 奢華游艇, 攔截免疫子系統的被動相關加成移除
 *截擊艦, 奢華游艇, 攔截免疫子系統會有新的特有加成
 *攔截免疫裝備 鎖定距離懲罰 及 重啟延時 -50%
 *攔截免疫裝備 作用時間 +100%
 *所有穿梭機增加被動攔截免疫能力

Warp Core Stabilizers (躍遷核心穩定器)
裝備的被動懲罰保留, 而躍遷核心強度加成僅在啟用時才生效:
 *電容需求 : 50
 *作用時間 : 20s
 *冷卻時間 : 120s
 *躍遷強度加成 : 2 <fs small>(CCP 帖子上寫的是 1, 但 sisi 上寫的是 2)</fs>
 *鎖定距離 : -50%
 *掃描分辨率 : -50%
 *無人機帶寬 : -50%

-----除此之外, CCP 正選擇一系列裝備能夠供在過門後隱形時能啟用。這新型攔截免疫裝備及躍遷穩定核心亦包括其中。玩家們還想甚麼裝備能在過門後就啟用, 請發表你們的意見。

-----截至 2021/05/18, 對方案的修改如下:
 *裝備槽位 : 由 低槽 改爲 高槽
 *可裝備艦船類別 : 移除 Stealth Bombers (隠形轟炸艦)
 *可裝備艦船類別 : 移除 T1 護衛艦
 *可裝備艦船類別 : 加入 T1 工業艦
 *截擊艦, 奢華游艇, 攔截免疫子系統 的 鎖定距離懲罰 及 重啟延時 加成由 -50% 增加至 -80%
