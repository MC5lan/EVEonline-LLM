# zh_guide_it_forums

====== 凛冬联盟社区(论坛) ======

^ 类别 | 论坛 |
^ 网址 | https://forums.winterco.org/ |
^ 状态 | 活跃在用 |

===== 简介 =====

凛冬联盟社区论坛是联盟用于长期讨论、公告归档和资料沉淀的平台。与 Discord、QQ 等即时通讯工具相比，论坛内容更适合被搜索、引用和长期保存，因此适合发布招募信息、教程、公告、政策讨论、服务请求、市场帖以及其他需要保留记录的主题。

===== 访问方式 =====

 - 打开 forums.winterco.org。
 - 使用你的 WinterCo 账号或指定的联盟认证方式登录。
 - 首次访问时，请按页面提示完成账号设置，并等待论坛权限同步。
 - 如果无法登录，或看不到应有板块，请先确认联盟服务注册已完成，再联系联盟 IT 支持。

===== 基本使用 =====

 - 发帖前先搜索，确认是否已有相同或相关主题。
 - 选择最符合内容的板块发帖。
 - 使用清晰标题，并在正文中提供角色名、军团、时区、日期、舰队、星系、相关服务等必要信息。
 - 发帖前阅读置顶帖、模板和板块规则。
 - 同一事项尽量集中在同一主题中讨论，避免重复开帖。
 - 对重要板块或主题使用关注/订阅功能，以便接收更新提醒。

===== 发帖注意事项 =====

- 不要在公开或权限过宽的板块发布敏感作战信息。
- 招募、市场、服务请求和支持请求应发布到对应板块。
- 紧急作战沟通请使用指定即时通讯渠道，不要依赖论坛。
- 保持内容礼貌、清晰、可检索，方便其他成员后续查找和引用。
