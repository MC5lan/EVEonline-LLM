# 0.1-0.4区域新兵守则

你必须明白,这个区域开始,已经不再有NPC警察会保护你的安全,你不能任何时候都在哨戒炮的射程之内,而且哨戒炮也不一定能真正的置你的敌人与死地。

## 要点

- 任何时候不要忘记给你的船装备上"跃迁核心稳定器"，它是让你躲开被敌人干扰跃迁的保障，是你活下来的希望，所以重视它点，再重视它点。
- （目前，曲跃核心稳定器对舰船锁定速度和锁定距离有较大的惩罚。可以在跑路的时候装上稳定，到任务地点空间站再换下来。）
- 如果在星门或空间站附近被人锁定，不要慌乱的开火，否则攻击你的不仅是你的敌人，还有NPC炮台。
- 进入陌生区域前,使用星图功能看看你的路线上的爆船爆蛋记录,尽可能绕开有潜在危险的星系,绝对避免进入正在会战的星系。
- 大多数的玩家军团都仅仅对蓝名(高声望)玩家保持友好,如果你想进入的地方，是你相对于他们是白名或者红名的,那么有大概率你会被当成是敌人的眼睛或者敌人，如果你不及时出去的话，你很可能会被攻击。当你进入那些军团领地的时候,请一定要记住这一条。
