# 0.1-0.4区域新兵守则

单独拉出你的本地聊天频道,避免它被任何东西遮挡,这是你最好的预警线。

你必须明白,这个区域开始,已经不再有NPC警察会保护你的安全,你不能任何时候都在哨戒炮的射程之内,而且哨戒炮也不一定能真正的置你的敌人与死地。

不要使用自动导航，必须手动迁跃到你希望到达的地方。

任何时候不要忘记给你的船装备上"跃迁核心稳定器"，它是让你躲开被敌人干扰跃迁的保障，是你活下来的希望，所以重视它点，再重视它点。

（目前，曲跃核心稳定器对舰船锁定速度和锁定距离有较大的惩罚。可以在跑路的时候装上稳定，到任务地点空间站再换下来。）

如果在星门或空间站附近被人锁定，不要慌乱的开火，否则攻击你的不仅是你的敌人，还有NPC炮台。

进入陌生区域前,使用星图功能看看你的路线上的爆船爆蛋记录,尽可能绕开有潜在危险的星系,绝对避免进入正在会战的星系。

多去论坛,多了解游戏里军团间的形势,如果你进入一个冲突区,无疑是极其危险的。

大多数的玩家军团都仅仅对蓝名(高声望)玩家保持友好,如果你想进入的地方，是你相对于他们是白名或者红名的,那么有大概率你会被当成是敌人的眼睛或者敌人，如果你不及时出去的话，你很可能会被攻击。当你进入那些军团领地的时候,请一定要记住这一条。

如果你遭遇海盗,并遭受勒索的话,迅速评估所有的因素,比如战斗胜负几率,你的爱舰价值,舰内货物价值,勒索额,海盗玩家是否曾有付钱后依旧撕票的恶行.然后作出决定付钱或者战斗或者逃跑,如果你正好有朋友在附近,你也可以马上叫他们来解救你。

如果爆船无可避免,请反复尝试跃迁,尽可能的保住自己的逃生仓。

在这个区域内如果你攻击其他玩家,都会降低你的安全等级,如果你摧毁他人的逃生仓,每次会降低0.5的安全等级,当你安全等级过低的时候,你再次进入0.5以上区域会被警察攻击,在0.1-0.4内也可能会被攻击。

按ESC 通用设置-自动拒绝邀请，这个要选中，防止和玩家PK时，对方一人，或者多人狂按CTRL和左击你的名字，发送对话请求，致使你被卡，然后被爆。

如果不幸被海盗抓住，保持理智和冷静，不要觉得新手就是上帝，导弹永远比口水有用，还是多想想怎么反击，逃跑或者减少损失，激怒海盗是最愚蠢的行为，当然如果你认为激怒海盗，并让他叫上他的同伴，在你长期活动的地方见你一次杀你一次，是很舒爽的一件事情，那你尽管去做吧。

如果你想安全的在0.4以下刷怪，首先你得考虑下那个星系的交通状况，很多0.4以下星系都是交通发达地区，很多人员会经过，找些偏僻一点的星系，不要随便离开帝国高安控制区很远，那样很危险~~ 比如 G族帝国区就控制了0.4瑟伊林-0.3安尼这2个地方，都很偏僻，几乎没人来，而且在高安区附近，不在交通线上~~
