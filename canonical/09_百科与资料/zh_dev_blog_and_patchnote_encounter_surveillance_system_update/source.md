====== 重塑事件監測裝置 ======

--------\\原文鏈接: Encounter Surveillance System Update

</jumbotron>

大家好。

統合部現正對 Encounter Surveillance System - ESS (事件監測裝置) 進行重大調整。新的 ESS 設定將會與 concord_introduces_the_dynamic_bounty_system 同時推出, 兩者配合下將會重塑目前 0.0 地區的刷怪邏輯。

-----

-----

<fs x-large>過去的 ESS</fs>

原本的 ESS 設定是爲 0.0 地區玩家提供一個增加面對被盜取收入的風險的同時,增加星系內刷怪收入的機會。此理念非常清晰但聰明的玩家們已經指出了有幾項與 風險/獎勵 有關 以及 部署位置 的問題, 這顯示出 ESS 系統有很多可以改進的地方。直至現在, 是時候從獲得的經驗中學習, 對設計重新審視, 更聚焦於 0.0 地區創造更多衝突的機會。

-----

-----

<fs x-large>調整重點</fs>

 *ESS 不再是可供選擇的部署選項, 將會預設部署於所有 0.0 星系。
 *ESS 的部署地點是全星系公開的，並且需要通過設立了艦船級別限制的加速軌道才能前往。
 *ESS 將會自動支付其收繳的額外賞金, 玩家不需要親自去收取賞金。

-----

<fs x-large>搶錢去</fs>

就如目前的 ESS 般, 一部份的刷怪賞金收入將會被 ESS 收繳而非直接支付到玩家錢包。
而與目前 ESS 不一樣的是, 收繳的賞金將分開兩份儲存:

 *<fs large>主要</fs> : 大部份收繳的賞金都會儲存在這位置, 並且每 3 小時自動支付給回玩家, 但期間可隨時被入侵者提走。
 *<fs large>儲備區</fs> : 這是真正的大獎。賞金的一小部份會儲存在這區, 並且一直累積直至持有特定鎖匙的玩家前往偷取。在由儲備區偷錢時, 賞金隨時間支付給玩家, 速度會緩緩上升, 到最高速度後又下降回去。玩家需要決定到底想要在提款機前等待多久, 想要偷取多少金額才離開。此鎖匙稍後由多個遊戲渠道中獲得。至於怎樣獲取, 及相關的時間設定是多少, 將會視乎新設定實裝後的玩家反應再作調整。

對於那些數據黨來說, 你們需要等待新設定正式推出後在遊戲內自行發掘了。

-----

<fs x-large>掙飯吃</fs>

新的 ESS 有一系列規則鼓勵 PVP 對戰及避免那些惡搞的戰術。此 ESS 規則將會影響其半徑 75km 內的艦船, 包括:

 *不能躍遷
 *不能使用微型跳躍引擎
 *不能使用微型躍遷引擎
 *不能隱形
 *不能使用誘導力場
 *不能激活纖維

總括而言, 這些限制都是爲確保真正想去偷錢的玩家, 有敢於一戰的準備才去。當然, 視乎一系列新限制所衍生的新戰術, 在有需要時作出調整。

令人期待着新 ESS 的設定如何影響新伊甸。不論是保護自己的地盤, 或是計劃搶劫的海盜, 都會有更多新的選擇。
