# 0.0守则

离开这里,这不是一个新兵应该来的地方

如果你坚持要留在这里的话,请先买好最贵的保险，然后写好遗嘱

记住，00区域最大的问题是你的心态。如果你能够不怕爆船，不怕被捏蛋。那么00跟高安没什么区别。

00一般逃生术以及避免被抓方法：

1. 微曲反冲门：当你开着不会隐身，并且船比较硬的时候，可以超载微曲，然后打开微曲全力反冲门，跳门，记住一定不要开火。幸运的话，对方的抓人船全部开火打你，这样因为开火后有过门时间惩罚，所以只要在你进入星门2500米之前没爆，你多半能够逃脱。

2. 非隐跳船（带着隐身的战列之类）秒跳： 这招只有在没有泡泡的时候管用，同样需要一个微曲。当你过门后，如果看见有人在门边堵门，选择一个离你船头角度最小的可以跃迁的目标，开始对齐。在你解除过门隐身的瞬间，打开微曲，然后打开隐身。打开隐身后你的微曲会自动关闭，你会发现你的速度不断下降。等速度下降一点以后（取决于不同的船，不可以等太久），解除隐身，跃迁。你会发现你能在1秒内跳出去，对方无法反跳你。注意用这招，如果对方有经验丰富的小船，他会把你撞出来，那时就只好反冲门。

3. 隐跳船（隐身轰炸之类）过被泡泡堵住的星门： 过门之后发现被泡泡堵住，无法隐跳？ 选择一个离开泡泡的方向，加速的同时打开微曲，手快的可以顺便超载再打开。微曲打开的同时点隐身，利用惯性加速飞出泡泡。 一般情况下这是完全无法抓住的，即使截击带无人撞你，只要你走位够猥琐，完全撞不出来，因为超载微曲的小船速度太快。

4. 00地区跳门常识： 当本地有白名红名的时候，如果你过门没有看见敌人，那么不要直接跳下一个行星的星门，而是跳到那个星门边上的行星。利用直接扫描扫那个门，看看是否有泡泡和船。如果那个门周围没有行星？那么你先随便跳一个行星，或者安全点。选择那个星门，点跃迁，你会发现船在起跳前就消耗了跃迁需要的电，然后停船停止跃迁。如此反复几次，把电消耗到不多的时候，再跳门。你会发现系统提示你电量不足，只能有多远跳多远，如此你就不会跳到星门面前可能存在的泡泡里面了。就这样反复几次，直到目标星门进入你的扫描范围，做点，下次还可以用。

5. 00刷怪，本地来人，立刻跳POS或者安全点，用直接扫描查看对方船只类型。你也可以选择牺牲锁定速度，带上一个隐身，如果对方不走，你就在安全点隐身住，睡个午觉什么的。
