# 击杀权

===== 什么是击杀权？ =====

当另一名玩家通过激活船上的进攻武器对你进行攻击时，你将被授予击杀权。 统合部用犯罪标志（闪红骷髅头）标记犯罪飞行员。作为目标玩家，你将获得对攻击者的击杀权。

只有在高安中发生犯罪侵略或在低安攻击逃生舱时，才会出现击杀权。 低安中的所有其他违法行为都会将犯罪者标记为嫌疑犯，因此不会产生杀戮权。在0.0和虫洞空间中的所有攻击都是合法的并不会产生任何击杀权。请记住，如果你因为某些原因是高安或低安中犯罪者的合法目标，则攻击你没有任何后果，不会产生击杀权。

使你成为合法目标的情况是：

 嫌疑标记 - 黄骷髅头（15 分钟计时器）
 犯罪标记 - 红骷髅头（15 分钟计时器）
 有限参与标记 - 蓝色双剑（5 分钟计时器，从攻击停止的那一刻开始倒计时，如果在该时间内攻击则重置）
 成为战争目标 - 红色双剑（仅适用于参与战争的双方）
 安全等级等于或低于 -5.0

你的船不需要被摧毁就可以获得的击杀权。

===== 寻找可用的击杀权 =====

在游戏中打开你的角色窗口，然后单击交互选项，然后选择击杀权。只需单击你想要激活的选项，然后选择你想要的选项。 比如你向谁提供击杀权，以及你是否会为使用该击杀权收费。

===== 出售击杀权 =====

如果你拥有击杀权，你可以选择将其出售给其他飞行员。 你可以从角色表/击杀权限选项中选择要出售的击杀权。 打开击杀权选项后，你将看到三个按钮，你可以通过这些按钮选择授予哪些权限：1) 所有飞行员，2) 你的公司，或 3) 特定命名角色、联盟或公司。 如果你选择出售击杀权并且被另一位飞行员接受，则无论是否进行击杀，ISK都将立即转移给击杀权所有者。在没有任何成本影响的情况下，任何人都可以激活击杀权； 然而，没有什么可以阻止犯罪的飞行员在新手船上找一个朋友或一个小号来杀死他，以清除击杀权。

===== 激活击杀权限 =====

如果您你得了一个击杀权并激活了它，违规的飞行员将开始闪烁一个疑犯标记（闪黄骷髅）请记住，如果你向他开火，你将被标记为有限交战计时器，而他可以还击。

要在拥有击杀权的玩家身上激活击杀权，你首先需要与他们在一起。默认情况下，在你选择有击杀权的玩家后，他的图标右上角会出现一个十字准线图标。请注意，杀戮权将有一个价格，从 0 isk 或更多。如果你拥有该飞行员的击杀权，则无需支付任何费用即可激活。

对安全等级为 -5.0 或更低的飞行员激活击杀权没有意义，因为任何飞行员都可以攻击他们。
