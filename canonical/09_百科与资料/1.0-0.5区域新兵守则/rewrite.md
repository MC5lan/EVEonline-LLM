# 1.0-0.5区域新兵守则

如果你对你的机器没有百分之百的信心,那关掉声音还有LOG记录,可以让你卡屏或者掉线的几率减小很多.

## 要点

- 重要的提醒功能不要关闭,比如自曝,弹射,销毁等,已经关闭的可以在ESC菜单里重新启用.
- 不要轻易在0.5以上的区域内使用立体炸弹和FOF导弹这两种武器，即使你的身边没有别人，这些不能由你控制攻击目标的武器如果无意中误伤到玩家或者一些建筑，你都会被警察叔叔打到爆船为止的.
- 如果不是绝对安全的环境，请保持和最近的建筑10KM以上的距离，除非你很想体验在你撤退的时候被卡在建筑或者小行星中间的感觉。
- 你很想作一个后勤者，所以你学习了远程维修技能装备了远程维修的设备，或者带着远程维修类的无人机，但请不要随意在0.5以上区域使用，否则后果自负。
- 有些战利品不要轻易放进你的货柜，比如“小型军械”“葳砣柯”等，不然海关人员会以走私违禁品的名义对你进行罚款、没收违禁品、降低势力声望的处罚，如果你妄图武装走私，你会被就地击毙。所以当你看见一个你不熟悉的战利品的时候，请点击它的属性，看看是否有《合法性》一项，如果有，相信我，放弃它是最好的选择。即使你立即跳往 0.5 以下区域都不能逃过海关，因为你还要过星门。
