# 1.0-0.5区域新兵守则

如果你对你的机器没有百分之百的信心,那关掉声音还有LOG记录,可以让你卡屏或者掉线的几率减小很多.

重要的提醒功能不要关闭,比如自曝,弹射,销毁等,已经关闭的可以在ESC菜单里重新启用.

不要攻击你的队友打出的箱子,这样做会被NPC警察攻击.

不要轻易在0.5以上的区域内使用立体炸弹和FOF导弹这两种武器，即使你的身边没有别人，这些不能由你控制攻击目标的武器如果无意中误伤到玩家或者一些建筑，你都会被警察叔叔打到爆船为止的.

如果不是绝对安全的环境，请保持和最近的建筑10KM以上的距离，除非你很想体验在你撤退的时候被卡在建筑或者小行星中间的感觉。

你很想作一个后勤者，所以你学习了远程维修技能装备了远程维修的设备，或者带着远程维修类的无人机，但请不要随意在0.5以上区域使用，否则后果自负。

有些战利品不要轻易放进你的货柜，比如“小型军械”“葳砣柯”等，不然海关人员会以走私违禁品的名义对你进行罚款、没收违禁品、降低势力声望的处罚，如果你妄图武装走私，你会被就地击毙。所以当你看见一个你不熟悉的战利品的时候，请点击它的属性，看看是否有《合法性》一项，如果有，相信我，放弃它是最好的选择。即使你立即跳往 0.5 以下区域都不能逃过海关，因为你还要过星门。

当你装甲已经被攻击到一定程度，或者你发现你的护盾和装甲损失的速度很快的时候，请马上做好撤退的准备，否则一切就太迟了。

学习秒跳可以让你更容易在残酷的战场中活下来.

不要随便乱拣别人的箱子,否则你很可能成为别人攻击的目标.而且警察不会帮你.

如果有人偷你的箱子,而你又很有信心干掉他,那就干掉吧,不过事后记得跑空间站里蹲上15分钟,以避免被报复.15分钟以后你就安全了.从你和他战斗结束的那一秒算起.

极品是用来收藏的,在0.5-1.0的区域内,极品装备的用处没有那么大,而且,你还可能被某些恐怖分子自杀式攻击掉,

战斗任务,尤其是高级战斗任务往往很危险,如果你不是很熟悉该任务,你可以开着穿梭或者你的逃生仓去侦查一下,再作任务,

将军难免阵前亡,如果你在战斗任务里爆了船,那记下坐标,回去拒绝任务后,回来安全的拿走自己的遗产吧.

如果你不想被卷入战争,就不要加入你不熟悉的军团或者和不熟悉的人组队,如果你所在军团或者你的队友正在战争状态,那么你也会进入和他们相同的状态（比如敌对军团，和对你的队友闪红的人都可以合法攻击你）

如果你对其他玩家进行跃迁干扰、ECM干扰、等等阻扰玩家举动,都会被警察攻击.当然，你可以用舰船扫描扫或者货柜扫描一下玩家或者警察带了什么装备，不会被警察攻击的，其他动作不能保证。

自动导航很方便，但是当你拥有了很好装备的舰船（或者用工业舰装载了很多贵重物品）时，请不要使用自动导航。因为从迁跃停止之处到星门有15KM的距离，足够心怀不轨的人扫描你的货柜并在警察干预之前将你击毁。
