28/10

===== 活動 =====
 *Crimson Harvest 活動開始, 活動期至 9/11
 *期間限定的作戰及破譯據點將出現於高安, 低安, 0.0, 蟲洞星系, 血襲者同盟(Blood Raider Covenant) 及 聖特里蒙兄弟會(the Order of St Tetrimon) 兩勢力將相互交戰。
 *Crimson Gauntlet 及 Tetrimon Base 據點可以於所有地區找到。玩家應該小心前往這些據點, 建議使用戰列巡洋艦, 戰列艦, 重型突擊艦, 或其他更強力艦船前往攻略。擊毀據點最後出現的戰列巡洋艦 NPC 將能領取獎勵, 包括 ISK 兌換品, SKIN, 增效劑, 衣飾等。
 *Crimson Harvest Network Node 及Tetrimon Network Node data sites 可於所有地區找到. 破譯這些據點將可獲得豐厚獎勵。
 *由 Blood Raider 控制的 絕地(Delve) 星域, 德里克(Derelik) 星域中的低安星系等, Blood Raider 及 Tetrimon forces 的衝突更爲激烈, 玩家可以在這些地區找到高級的作戰及破譯據點。這些高級據點更爲稀有及更具挑戰性, 其獎勵亦更爲豐厚。帶上一兩位小伙伴一起攻略可大幅降低風險, 但請注意或許亦有其他玩家也在找尋這些高獎勵據點。
 *Blood Raiders 及 the Order of Tetrimon 的要塞只可能透過攻略高級作戰據點中罕見的遠征訊號才能找到。
 *Blood Raiders 及 the Order of Tetrimon 會向協助他們的玩家提供獎勵。每一位玩家都可以於 Agency 中選擇爲兩者之一效力。不論選擇爲那一方效力, 攻略其敵方都能獲得相同的積分點數, 亦會收到玩家選擇的派系為題獎勵內容。請注意玩家只能夠透過攻略其所選擇勢力的敵方以獲得 Agency 積分點, 但向雙方攻擊並不會有任何懲罰, 均可攻略雙方據點獲得獎勵。
 *於 Crimson Harvest 活動期內, 玩家可以獲得特別的每日登錄獎勵。包括新 SKIN, 限時增效劑, 數十萬技能點等。
 *不給糖就搗蛋! 於 Crimson Harvest 活動期內, 所有玩家艦船被摧毀後的戰利品掉落率將提高, 由以往的 50% 提高至 90%。殘骸圖標亦會更換成活動式樣。
 *Crimson Harvest 主題的深淵競技賽季亦於 29/10 - 2/11 展開。本次賽季爲 4玩家 T1 驅逐艦的 Free-For-All 混戰, 而停滯纏繞光束、電容戰、能量武器傷害 會有特殊加成, 使每艘驅逐艦都能擁有如血襲者船的性能。

===== 建築及部署 =====CONCORD Rogue Analysis Beacon 正式向玩家推出。這部署裝置爲玩家提供新的 PVE 活動及新的獎勵。裝置有4個環節 : 部署, 連結, 掃描, 獎勵。
 *裝置屬性
 *技能需求 : Anchoring III
 *只能於 0.0 及 低安星系部署
 *部署時間 : 20秒
 *壽命 : 1小時
 *護盾/裝甲/結構 : 50,000/50,000/50,000
 *部署 & 連結
 *裝置投放後, 將會全星系總覽可見並能直接躍遷前往。
 *裝置部署後, 玩家可以駕駛 : 航空母艦, 無畏艦, 超級航空母艦, 泰坦 以連結裝置。
 *艦船開始與裝置連結後, 將使艦船停留在該位置 4分鐘。
 *於連結時, 艦船將 : 不能被繫泊, 不能隱形, 不能躍遷, 所有抗性(護盾/裝甲/結構) 提高 10%。
 *連結完畢後, 上述四種狀態將會結束。
 *掃描
 *連結時, CRAB 會開始於星系中廣播信號以吸引自由無人機 NPC 的注意。
 *當自由無人機接近 CRAB 時, 他們會阻止掃描進程並攻擊 CRAB 附近的敵對威脅。
 *玩家需要清除週遭的自由無人機以讓 CRAB 繼續完成掃描。
 *掃描達 10分鐘後, CRAB 將完成對自由無人機的掃描, 並將向玩家獎勵新型突變質體。
 *奬勵
 *掃描完畢後, 玩家可以於 CRAB 中提取其經掃描自由無人機後所產生的新型突變質體。
 *掃描完畢後的 2分鐘內, 於掃描階段連結 CRAB 的艦船將獲得由 CRAB 中拿取物品的唯一權限。
 *掃描完畢後的 2分鐘後, CRAB 將會啟動自毀程序, 其於掃描時所產生的突變質體將必定遺留於其殘骸中。

===== 系統 =====
 *恆星系將有一項新的數值 : Signal Interference (信號干擾度)
 *在重覆使用新型 CONCORD Rogue Analysis Beacon 裝置時, 會使星系的信號干擾度趨向飽和, 阻止更多的 CRAB 於恆星系中廣播信號。即是 : 當信號干擾度太高時, 玩家將不能連結 CRAB, 自由無人機亦無法發現 CRAB 所廣播的信號。
 *星系的信號干擾度會隨時間慢慢回復至一般水平。回復將會持續進行而不受伺服器維護所影響。
 *星系由最高信號干擾度完全恢復需時大約 25小時。
 *玩家的星系信息介面將會顯示星系的信號干擾度。
 *玩家將有一項新的數值 : Complex Encryption Qubits 複雜加密量子元 (CEQ)。
 *玩家在連結 CONCORD Rogue Analysis Beacon 時需要消耗 CEQs。
 *CEQs 會隨時間慢慢回復至最高儲備量。回復將會持續進行而不受伺服器維護所影響。
 *CEQs 由0回復至最高儲備量需時大約 22小時。
 *連結 CRAB 只消耗 CEQs, 玩家當前的 CEQs 儲備量可以於 CRAB 的浮動提示上查看。

===== 原生 Mac 客戶端 =====
 *原生 Mac 客戶端推出。玩家必需以最新版本的登錄器運行以更新客戶端。
 *停止支援 MacOS 10.13
 *Wine 客戶端過渡至 Mac 客戶端:
 *MacOS 上 EVE Online 客戶端的安裝路徑因爲不再需要運行 Wine 而有所不同。登錄器會驗證文件以確保都是有效的, 並且刪除不需要的文件。驗證過程基於硬碟讀取速度需要一些時間。
 *Tranquility 的客戶端設定將會由 Wine 客戶端複製至原生 Mac 客戶端。
 *登錄器於往後的更新中將會移除舊 Wine 客戶端中剩下的文件夾。
 *與 Wine 客戶端相比, 鍵盤快捷鍵的設定有重大改動:
 *玩家若有自設過快捷鍵, 需要檢查一下新的快捷鍵指令:
 *以下文本格式和複製/粘貼快捷方式已更改為主要使用 Command (Cmd) 而不是 Control 鍵, 以與默認 macOS 體驗保持一致, 並避免與其他快捷方式發生衝突：
 *Cmd+C, Cmd+V, Cmd+X, Cmd+A: Copy, paste, cut, and select all - are now using standard commands on macOS.
 *Cmd+Left, Cmd+Right - move cursor to the start or end of the line.
 *Opt+Left, Opt+Right - move cursor one word left/right.
 *Cmd+B, Cmd+I, Cmd+U - bold/italic/underline.
 *F11 (星圖) 修改至 Opt+B。這是由於在某些 macOS 系統上可能會發生操作系統快捷方式衝突。由於「顯示桌面」快捷方式, 於操作系統會阻止客戶端使用 F11 作爲快捷鍵。如果玩家希望在客戶端中使用 F11, 可以在 macOS 上的「任務控制」中更改此選項。
 *客戶端現在支持左右選項修改鍵。這使 macOS 客戶端與 Windows 客戶端保持一致, 快捷操作等亦可以正常工作。 例如： left opt + A 將打開字符表，而 right opt 可用於該鍵的替代字符輸入。
 *在目標之間移動快捷方式（在 Windows 上：Alt+Left / Alt+Right）已重新設定到 Ctrl+, / Ctrl+。 以避免與 MacOS 快捷方式發生衝突。
 *停止飛船的默認快捷鍵已重新設定為 Shift+Space。
 *為 Mac 客戶端修改了其他幾個默認鍵盤快捷鍵, 玩家可以在 ESC - Shortcuts 檢查。
 *Intel 的 Mac 客戶端支援 SpaceMouse 使用, 但目前亦未支援 M1 系統使用 SpaceMouse。
 *之前已公告過, 有關個人技能規劃等項目目前並未支援原生 Mac 客戶端。將在日後更新中重新引入。
 *客戶端幀率會隨系統散熱程度調節。
 *Mac 上的鼠標光標現在具有更高的分辨率。
 *Mac 客戶端的 EVE 客戶端徽標已更新。
