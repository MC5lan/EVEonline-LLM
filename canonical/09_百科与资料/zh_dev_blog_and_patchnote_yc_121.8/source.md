===== 艦船及裝備 =====

 *社群配置方案將在一小部份領域推出。社群配置方案可以在已保存配置中查看，相關配置方案是由玩家們提交，再經 ISD 志願者審核。首批配置方案包括一系列基礎 Tech I 探索護衛，以及 Venture 採礦護衡艦的配置。日後會推出更多不同領域的配置方案。

===== 宣戰 =====

 *沒有戰爭總部非雙邊戰爭的過渡期完結。所有沒有戰爭總部的非雙邊戰爭將會在下一次進攻方繳付戰爭費用時進入 24小時結束倒數。
 *重新設定基於一方投降 或 戰爭總部被摧毀後的強制停戰時間。每一款強制停戰都會分開計算時間。

===== 植入體 =====

 *＂Slave（斯拉夫）＂海盜植入體將改命名＂Amulet＂植入體，以便在未來調整那一個海盜勢力爲玩家提供這些植入體。是次調整並未影響植入體的任何功能。

===== NPC =====

 *於入侵區域外，有報告指發現 Triglavian 的偵察艦船。

===== UI =====

 *公司信息中的戰爭分頁中，＂All Wars＂分類中加入說明此信息延遲顯示時間爲 15分鐘。
 *複製文字輸入區域中的文字將會包含所有格式資料。玩家可以在右鍵選單中選擇不包括格式的複製操作。
 *裝備右鍵裝填彈藥選單，每款彈藥前綴將顯示該彈藥最高的兩項傷害屬性。彈藥選單亦會以彈藥的射程（最佳＋1倍失準）排列。
 *改善導入技能學習方案。在導入技能時，如果該技能的前置技能需求並不滿足，那這些前置技能亦會一同被導入。而導入技能失敗時亦會彈出提示視窗，玩家可以直接購買所欠缺的技能並繼續進行技能導入的操作。
 *忠誠點商店的商品分類將作出調整，該空間站擁有者的基礎忠誠點商店將會優先顯示。
 *艦船信息視窗的標題欄加入顯示該艦船的類別。
 *技能的信息視窗將加入一個供玩家直接購買該技能的按鈕。
