# zh_dev_blog_and_patchnote_20.01

<image shape="circle">作者: Rabbit P MuraSaki Siki</image>\\官网公告链接: Patch Notes For 20.01 Release \\

## 要点

- ===== 活動 =====  *Interstellar Convergence 活動開始。此與 Doctor Who (神秘博士) 的限時活動將持續至 1/2。  *活動包括各專門的傳送纖維供新玩家遊玩及老玩家挑戰。活動主題是探索, 亦包括作戰及工業製造元素。  *"Warp Matrix Convergence" 遺跡信號將於新伊甸所有領域出現, 通過探針定位來開始參與是次活動。  *使用遺跡分析儀以收集用於製造活動傳送纖維的藍圖及材料。  *Curious, Enigmatic, Mysterious Warp Matrix Filaments 可供玩家和平地探索破譯。  *Precarious, Hazardous, Dangerous, Perilous Warp Matrix Filaments 則有致命的生物機械敵人供玩家挑戰。  *活動亦有專門的挑戰點數奬勵, 以及每日登錄獎勵。  *探索這些據點將可以獲得 賣 ISK 的物品, 新款 SKIN, 獨特人物服飾, 增效劑, 大腦加速器, 煙火, 以及特殊的 Doctor Who 彩蛋收藏品。
- ===== 音效 =====  *重新調整各探索據點的音樂播放, 主要是避免兩首音樂同時播放。現時有部份據點將會不會有音樂。
- ===== 技能 =====  *儲存別人分享的技能規劃, 將會於個人技能規劃中創建一份副本。
- ===== 系統 =====  *停止支援 DirectX 9。這代表不支援 DirectX 11 的 PC 將不能夠運行 EVE 客戶端。
- ===== UI =====  *🤝纖維將可以保存於艦船配置中。  *🤝艦船信息視窗中加入一個按鈕, 以直接前往艦船模擬配置頁面。  *🤝加入快速調整艦船陣型的功能。  *改善 Help pointer (指示光標窗口) 功能。
