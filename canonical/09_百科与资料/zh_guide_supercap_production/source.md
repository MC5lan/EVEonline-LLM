# zh_guide_supercap_production

====== WC 凛冬旗舰安全生产指南 ======

<text type="primary">By 原礼辛 Amethyst Shock</text>

由于最近境内频繁受到墩子以及隐轰队的骚扰，并且新人旗舰驾驶员缺少安全生产的必要常识，我认为有必要写一份安全生产指南。本指南内容都是我的个人习惯，大家不必完全照搬，我只是想要推荐一种安全生产的方法，相信当你们阅读完此篇指南后，生产的安全系数会大幅上升，甚至能把对面的收割队变成送肉队，让你的心态从看见红白时的心惊胆战、语无伦次、不知所措转变成看到收割队就饥渴难耐，恨不得往自己的宝船上再镶几颗星。

===== 开工前必须要知道的 =====

==== 登录你的Mumble ====

首先你应该已经提交了 SeAT，在 SeAT 页面左侧 Mumble 选项下有一个登录凭据，里面有你登录 Mumble 的账号密码和服务器，具体怎么提交 SeAT，怎么使用 Mumble，我不再重复，相关教程可以参考：

https://frt-fuxilegion.gitbook.io/project/

已经非常详细了。开工前请 确保自己说话能让别人清晰地听见，平时尽量保持麦克风和音响处于开启状态，害羞不说话没关系，至少被抓时一定要第一时间大喊，这是你能否成功被救下来的第一保证。

==== 预警 ====

首先请 一定 要加入预警频道 ''WC.Oasa+PF''，本地进红进白需要预警，预警时请先拖星系黄字，其次是敌对人名，如果看得到船型请拖船型黄字，看不到船型就写 ''NV''。如果本地大量进红不要写 ''大量''，请打出本地敌对的大致数量，如 ''100+'' ，并拖入一个敌对的名字方便 FC 了解敌对势力。如果可以，请做一份 D-Scan，将 ''Directional Scanner'' 设为 14.3AU 360°，Ctrl+A 全选定向扫描器内容，Ctrl+C 复制，Ctrl+V 黏贴进 D-Scan 网站（网址：https://dscan.info/ ） 。预警的具体样例如下：

''RF-X7V nextorian Slasher''（注意此处星系、人名、船型都需要拖黄字）

''RF-X7V 100+ Silvitni''（做完D-Scan之后附上一份D-Scan网址的链接）

预警频道严禁吹逼卖死亡报点，也不要乱打 ''Test''，也不要打 ''测试''，要测试预警软件写 ''RF-X7V Status''。

预警格式设置成这样的是有原因的，因为一个标准的预警能够方便一款预警软件（Near2）很好地读取信息，具体使用和安装方法见 zh:guide:near2 或 https://frt-eve.com/viewtopic.php?t=1118

当你安装好预警软件并且预警频道有预警后，一般会是这样的：

预警软件的制作方似乎停止了对软件的更新和维护，官方网站也下载不到了，所以大家还是继续看预警频道吧。如果要下载，可以从欧莎群里找到文件。

==== 界面设置 ====

界面设置没有强制要求，在这里我只是推荐我的习惯。首先请加入对应的舰队，小航、大航、诱导进 ''WC Standing/WC值守舰队''（一般是这个名），大鱼加入 ''WC Mining/WC挖矿舰队''。我生产时的完整界面如下：

可以看到，左下角为三个频道窗口，分别是舰队频道（或者报点频道），本地频道（尽量拉长方便观察进红进白情况），以及预警频道，预警频道上方是预警软件。右下角是 ''Directional Scanner'' 和 ''Probe Scanner''，方便观察星系敌人船型以及生产的异常或者矿带。你可以通过按 Alt+P 和 Alt+D 打开这两种扫描器，点击方块就可以把它们单独钉在想要的地方了。

然后是总览，总览确保设置正确能看到敌人和反诱导。如果你是多开党，最好将自己的号加入观察列表。

各个窗口的位置大家可以根据电脑屏幕大小和喜欢调整，但是我推荐你们能够将预警频道、舰队频道、本地频道、两个扫描器单独拖出来，并且能够同时将这些内容显示在界面上。

==== 反诱导 ====

反诱导（Mobile Cynosural Inhibitor）是敌对在抓你的时候很大概率会部署的一种装置，在它的范围内（以反诱导为中心半径 100km 的球体）你的诱导船是无法打开诱导的。反诱导上线需要 一分钟，上线时选中它可以看到一个绿色圆形的读条，可以看到上线剩余时间。请务必将反诱导加入总览，最好是单独总览，以便你在被抓时 及时汇报敌对是否下了反诱导，反诱导上线时间以及你的诱导船离反诱导的距离。

至于如何将反诱导加入总览，可以参考：

https://forums.winterco.org/t/topic/1626

==== 轻拦泡泡 ====

轻拦泡泡是一个半径 20km 的球，在它的范围内你无法启动你的跃迁和旗舰跳跃引擎。

轻拦泡泡的判定：泡泡是拦还是吸和你的目的地有关。如果从目的地往你船方向的 500km 线段上有泡泡，那你还没到目的地就会被拦；如果从目的地延长 500km 的线段上有泡泡，那你会被吸过去，也就是说会多跃迁一段路；如果以上两条线段没有经过球体，即使它们几乎相切于泡泡边缘，你也不会被吸或被拦；深空点泡泡一般没有用。

所以说如果大航被泡，大航在异常 0m，异常 0m 有泡泡，诱导无论是从哪个角度跃迁大航或者异常 100km，你都会被吸，不要考虑骚操作了。

一般应急截击会往异常上下拉一个 Ping 点，该 Ping 点与进场诱导连线不会经过任何泡泡，救援诱导可以隐跳该截击，这样就不会被吸。

PS：泡泡生效的判定取决于你 起跳瞬间 和目的地到你的 500km 线段和 500km 延长线段上是否有泡泡，在你起跳后新打的泡泡不会对你造成影响。

泡泡里可以开诱导，谢谢！（100km 内没有反诱导上线的情况下）

===== 小航安全生产指南 =====

==== 你必须要有的 ====

- 一条飙车配置的小航（底槽 4 DDA，加上若干皮球，中槽一个 500 推，其余随意，可以不要任何抗和任何防，船插用跃迁插，或者 T1 旗舰三角插）
- 若干个深空点（深空点请不要设置在异常密集区和铁壁的连线上）。

对这就是你必须要有的，飚起来。

==== 推荐你要有的 ====

一个诱导号，小航不强制要求有诱导号，但你至少应该已经在培养中了，毕竟你是要上大航的。

==== 生产习惯 ====

首先 看本地，有红白墩子，那请你换一个星系（尽量远离腹地，选一个偏僻人少的地方。什么？你说 RF- ？那再见！），确保本地无红白后，小航跳异常随机 50 - 100km，落地立刻朝向深空点，然后开刷。发现本地进红，立马收铁骑，铁骑太远就别收了，起跳深空点，不要犹豫，然后开一轮 500 推起跳铁壁，过程中不要停留太久，因为敌人可能会用作战针扫到你。如果你反应慢，直到总览出现了敌对才发现，请你立刻起跳深空点，不要管铁骑了。墩子（经常是带隐秘诱导的隐轰）抓小航的通用套路是先五度到你所在异常，隐身跳到你附近，爬到你身边，显形立刻锁你并反跳、开诱导。等你发现他到你被抓住不超过 2s，反应时间很短，这就是为什么不推荐小航在有墩子的地方刷怪。

如果是刷怪过程中突然旁边冒出个轻拦，那就说明敌对轻拦早就隐身在异常了，那么可能是敌人预判了你要跳的异常提前埋在了里面。所以刷怪的整个过程中都请不要朝向除了深空点的任何地方，刷完了一脚推子起飞下一个异常就行。但是出现这种情况已经晚了，你应该在本地进红的瞬间就收铁骑起跳深空点。

==== 如果你被抓了 ====

如果你严格遵守上述习惯，你被抓的概率几乎为 0，但是很不幸，你还是被抓了。那么请第一时间在 Mumble 呼救，呼救应当是这样的：“''我被抓了！我是小航！我小航还有 80% 甲！我在 3-J 星系的618巡逻队，对面50人隐轰队，我（没）有诱导，对面（没）有下反诱导，反诱导还有 n 秒上线，我的诱导隐身在反诱导 n 公里，我的诱导和小航在值守舰队。''”，同时将''星系黄字''、''人数''、''其中一个敌对的名字黄字''拖到预警频道。不过这个时候小航应该已经炸了……但是不管救不救得下来，你的信息对于 FC 来说是很重要的，此时你的任务已经基本完成了，剩下的就去申请补损吧。另外如果你有诱导的话可以参照超旗安全生产指南的操作。

===== 无畏安全生产指南 =====

==== 生产习惯 ====

Emmmm……怎么说呢，由于联盟里无畏刷怪去世的比较少见，所以自己怎么开心怎么来吧。但是一般有两种选择：

- 屌丝刷怪纯效率装 \\ 这种思路就是放弃所有抗性专堆输出，因为除了C无畏想要清掉护卫需要一定的转速，由于我没有使用过除了C无畏的其他无畏，所以对AGM无畏的配置不做讨论。配装以便宜和堆伤害、转速为主，买好保险，被抓了就等死。当然，我是不推荐这样的。
- 豪华配置土豪装 \\ 这种就是有梦想的无畏驾驶员。A无畏在无人机区中的表现比较好，并且A无畏相较于M和G无畏更加硬，可以使用稍微好一些的装备，在抗性上多下功夫。由于我是凤凰爱好者，根据文华大佬的攻略，我在这里给出一个C无畏的超硬配置。

无畏刷怪同样请选择没有墩子的星系，一般来讲，这个配置配上合格的船体技能能够轻松抗下 50 个到 80 个隐轰的攻击，导弹辅助技能够高的情况下刷怪效率在 45m 一跳左右，并且能够处理掉近身环绕的小护卫。无畏由于模块罚站所以在被抓时也没什么特别多操作可以进行，对着反诱导一顿输出就行，来什么打什么。如果你有诱导，可以参照超旗安全生产指南的方式求救。如果你没有诱导，也请按照小航的求救方式——汇报信息，并且抗得尽可能久。一个够硬的无畏可以让 50-80 人的隐轰队吃不掉你，同时 200 人的隐轰队也看不上你。无畏相比于小航会更安全一些，但是无畏过渡到泰坦的时间过长，所以一般推荐新人走小航——大航路线。

===== 超旗安全生产指南 =====

==== 你必须要有的 ====

- 一条联盟标配甲抗大航（Hel 滚），大航具体配置可以在 SeAT 网站中找到，点击''Fittings''。往后翻，目前在第五页，点击右边的绿色眼睛。如果你想要导入配置，复制下方的文字导入游戏装配即可。配置的高槽和中槽可以按自己喜好来，但是低槽必须至少有两个二八抗（不能是T2的也不能是势力的），两块统合部钢板（不能是T2钢板），并且船插必须是T2旗舰三角插。

以上七样装备是一个标配刷怪超旗必备的。没有的话请不要使用超旗刷怪。

- 若干个深空点（深空点请不要设置在异常密集区和铁壁的连线上）。
- 一个诱导号，诱导船请用有效配置，越肉越好，船里保证臭氧充足。

==== 推荐你要有的 ====

- 一套高辟邪套（虽然很贵，但是50%左右的甲量加成不是开玩笑的），10号插可以用HG-1005或者1006、1007、1008，根据你的经济能力选择。

- 同时推荐学甲加成技能（''Armored Command''和''Armored Command Specialist''）并且学满，这样你就能替代10号甲量插使用''Armored Command Mindlink''，配上双加成比甲量插更硬。

- 高槽推荐装上两个装甲指挥脉冲波，一个甲量弹药一个抗性弹药。

- 中槽带一万推和注电，注电防止没电无法旗舰跳，一万推起跳加强效率。
- 装甲被动抗补偿技能建议全满。

==== 生产习惯 ====

开工前上妈宝，看红绿灯，看ping，加正确的舰队（诱导号必须在WC值守舰队），诱导隐身至深空点，大航跳异常0m，落地可以朝向深空点或者铁壁（不关键但是有时候能救命），然后开刷。本地有墩子不要怕，只要你有诱导你就是十分安全的。大航最后一波怪刷出来时开始朝向下一个异常，打完最后一波报点起跳。如果发现有FC ping女妖，或者有敌对100+规模队伍起队信息，请把你的大航和你的诱导伴飞。具体操作是刷完这个异常并朝向下一个异常，诱导飞下个异常100km，确定异常情况，随后大航起跳。大航跃迁过程中把你的诱导再往外拉个30km。

这样的话当你大航落地时你的诱导应该与你的大航相距130km左右，这样是最安全的。另外诱导船除了开诱导，其他时候请永远保持隐身。

绿灯时期，在WC的保护伞下，一个130km的诱导基本就保证了你大航的绝对安全（前提是你的配置正确），几乎任何敌对的活动都不会影响你的生产。最后我建议诱导永远伴飞大航。

PS:关于为什么诱导船与大航保持130km：首先反诱导半径100km，你只有在100km以上才能开出诱导，其次如果你大航先被泡住了，诱导船再跳你大航100km大概率会被泡泡吸过去，这样你就无法开出诱导了。移动反诱导放置距离不会是离你大航0m，一般在0-20km左右，130km的诱导是一个比较舒服的可以开诱导的距离。

==== 如果你被抓了 ====

请第一时间在Mumble呼救，呼救应当是这样的：“''我被抓了！我是大航！我在3-J星系的618群，对面150人隐轰队（或者对面剑齿虎将我泡住），我大航还有90%甲！我有诱导（不准没有），对面（没）有下反诱导，反诱导还有n秒上线，我的诱导隐身在反诱导n公里，我的诱导和大航在值守舰队''”，（你是大航驾驶员，你应该把这段话背下来）同时将''星系黄字''、''人数''、''其中一个敌对的名字黄字''拖到预警频道。诱导船在舰队频道打''11111诱导''，大航在舰队打''XXXXXXX大航被抓''。记住一定不要自己乱开诱导，听从FC指令，不要慌张，等FC下指令开诱导再打开诱导（开诱导前解除隐身双击太空）。在做这些事的时候，放出你的反常规铁骑（两组轻铁和三组重铁），开始对反诱导进行疯狂输出。打得掉，很好，值守舰队有肉吃了；打不掉，没关系，你也能被救得下来。

那么……如果你不幸被抓时诱导船不在130km，那么有两种情况：

- 第一种情况，此时敌对大部队还未进场，本地敌人数量很少（只有一两个），只有若干轻拦在你身边打了泡泡，那么请在被轻拦打泡泡的时候第一时间跃迁你的诱导船到100km。此时你的诱导船一定会被吸，但是敌对还没进场，你的诱导还没被撞出来，那就请把诱导船在隐身状态下拉出泡泡。假设反诱导正在上线，你应该汇报上线时间，并询问FC是否需要开诱导，同时远离你的大航，往离反诱导100km以上的位置拉（操作诱导船的时候你的铁骑应该已经在打反诱导了）。记住时刻保持隐身。如果比较不幸，你的诱导被轻拦撞出来了，那请超载你的委屈和抗性，拼命往外拉，同时在妈宝汇报情况，拉出100km后关微曲停船，在速度500m/s以下时打开诱导，告诉FC诱导已亮。
- 第二种情况，敌对全部进场，并且已经下反诱导了（如果没有下反诱导可以征求FC意见跳大航0m直接开诱导），那此时你的诱导不要跳大航100km了，这时候你应该听从FC安排，FC的截击或者T3C会为你提供一个安全的Ping点，随后再根据指令隐跳你的诱导到这些船附近10km。

如果你的诱导船被打死了，也请不要绝望，相信此时已经有千万诱导船在赶来的路上了，你现在需要做的就是专心打反诱导，打掉之后开始清理身边的轻拦。
请明白，如果你的诱导船和大航始终伴飞并且相距130km左右，就不可能发生以上两种情况了。

最后，请时刻更新汇报场上情况，不要隐瞒或者欺骗，这是对FC和值守舰队成员的尊重。

PS：关于要不要诱导隐身贴大航在反诱导上线的一分钟内打开诱导。我的建议是不要，除非你是在Bait，或者在妈宝和FC有明确沟通和安排，不然的话在一分钟内调度救援是很困难的。

===== 大鲸鱼安全生产指南 =====

==== 你必须要有的 ====

- 一条联盟标配大鱼，同样见SeAT网站，一条标配大鱼至少要有：中槽两个T2全抗，一个T2电抗，两个旗舰注电，一个T2注盾，当然你也可以往豪华的方向配，比如两个皮A、统合部盾修、皮X盾提；高槽一个工业模块，一个无敌核心；低槽两个T2纳米薄膜，一个T2损控。

以上十一样装备是一个标配大鱼必备的。没有的话请不要使用大鱼挖矿。
- 若干个深空点（深空点请不要设置在异常密集区和铁壁的连线上）。
- 一个诱导号，诱导船请用有效配置，越肉越好，船里保证臭氧充足。
- 一个矿带的150kmPing点，关于这个Ping点，请注意是离最近的矿153km左右，离最远的矿尽量在200km左右，拉太远会导致你开不出无敌（锁不上矿，请注意你的锁定距离）。
- 无敌技能3以上，越高越好，能很大提升你的生存能力。

==== 推荐你要有的 ====

- 势力移动仓库，用来被抓时换装，同时可以放下三个儿子。
- 高槽的旗舰盾修，用来修你的儿子和小矿船。
- 如果多开大鱼可以在其中一条鱼上装两个盾加成。

==== 生产习惯 ====

开工前上妈宝，看红绿灯，看ping，加正确的舰队，大鱼加挖矿队，诱导加防御值守舰队。诱导隐身在大鱼群130km位置，同时离你的150kmPing点130km，这个位置看个人经验，差不多就行。离150kmPing点130km是为了防止大鱼在折返点被抓，反诱导下在折返点上。

诱导船位置

大鱼从150kmPing点跃迁你要挖的矿2500m。随后接近至500m左右，这么近是为了让你尽快收鱼儿子。锁矿，放儿子，锁上你的五个儿子，随时准备遥修儿子，放小屋，开模块开挖。保证所有主动抗永远处于开启状态。如果你是多开大鱼，建议将你的鱼都互相加一下关注，免得被抓操作不过来。

==== 如果你被抓了 ====

立刻收儿子，请第一时间在Mumble呼救，呼救应当是这样的：“''n条大鱼被抓了！我是大鱼！我在3-J星系的中型矿带，对面150人隐轰队（或者对面剑齿虎将我泡住），我有诱导（不准没有），对面（没）有下反诱导，反诱导还有n秒上线，我的诱导隐身在反诱导n公里，我的诱导在值守舰队，我的大鱼在挖矿舰队，我能/不能修住，无敌开/没开，无敌还剩n秒''”，（你是大鱼大佬了，你应该把这段话背下来）同时将''星系黄字''、''人数''、''其中一个敌对的名字黄字''拖到预警频道。诱导船在舰队频道打''11111诱导''，大航在舰队打''XXXXXXX大鱼被抓''。记住一定不要自己乱开诱导。同时把儿子掏出来放进身边的小屋里，放出你的无人机开始打对面轻拦，可以开着模块，注意自己盾量，对面毁电炸弹落地前不磕电池，毁完电后超载注电注盾抗性开始修盾。如果注电注不上来，就磕一节电池注一轮盾；如果修盾修不上来，在进3/4甲后开无敌。注意！如果你操作不过来，就开无敌吧！别忘了开无敌，这样死了是最可惜的。及时汇报所有大鱼无敌剩余时间（你可以从无敌BUFF上看到无敌的剩余时间），听从FC指令开诱导，开无敌后记得点红模块，并且尽量将盾修满。出了无敌后直到自己离场前不要放松，因为对面可能会飞回来强换你。

===== 总结 =====

虽然写了很多，但是大家可以发现不管哪种旗舰生产，必须要做到的事都是较为简单的，剩下的都是个人的生产习惯以及一些推荐，养成这些习惯能够让自己的生存力大大提升，也能够让敌人非常难受。无论是小航、大航还是大鱼，你们都应该知道凛冬的保护伞是十分强大的，敌人的收割队是不值得畏惧的。另外除了生产，大家也可以积极参与反收割呀，参加得多了也就明白敌人的套路了。搬来欧莎的两周里，我就在反收割中拿了四十几个 KB，虽然不多，我也很菜，但是慢慢攒星还是很开心的！你的旗舰不应当只是农具，不应当看见敌人就吓得不行，当你的船上镶满了星星，真正害怕的会是那些来收割的人。
