# zh_dev_blog_and_patchnote_rolling_thunder

CCP 計劃於 22/9 推出 Rolling Thunder 更新, 將對 EDENCOM 艦船等作出調整, 並且於 25-27/9 推出每日登錄獎勵。

## 要点

- 所有尺寸 Vorton Projector (電弧弦投射器) 的傷害衰減系數下調, 這將會使目標速度所造成的傷害衰減作用將下降。  *護衛級 : 0.6 → 0.4  *巡洋級 : 0.65 → 0.5  *戰列級 : 0.82 → 0.7
- 小型及中型 (Tech 1 及 Tech 2) Vorton Projector (電弧弦投射器) 的傷害上調；  *小型 Condenser Pack (電容包) 傷害上調 20%  *中型 Condenser Pack (電容包) 傷害上調 20%
- Sin (罪惡級):  *護盾抗性:  *熱能 : 20% → 35%  *動能 : 50% → 64%  *裝甲抗性:  *熱能 : 35% → 47%  *動能 : 45% → 60%
- Redeemer (救贖級):  *護盾抗性:  *動能 : 43% → 53%  *爆炸 : 55% → 68%  *裝甲抗性:  *動能 : 29% → 41%  *爆炸 : 28% → 49%
- Panther (黑豹級):  *護盾抗性:  *電磁 : 10% → 37%  *熱能 : 24% → 37%  *裝甲抗性:  *電磁 : 64% → 75%  *熱能 : 38% → 49%
