====== 勢力戰爭改革 ======

-----\\原文鏈接: https://www.eveonline.com/news/view/state-of-the-union

</jumbotron>

大家好。

Fanfest 2022 已過去了數月, 當時公佈說會對勢力戰爭有大型更新。在此期間, CCP 努力地將演講內容及玩家反饋落實為遊戲內容。

勢力戰爭中有很多令人興奮的內容, 在今年稍後時間推出更新前, CCP 將會適時跟大家分享項目開發細節。

===== 前線星系 =====

在考慮目前勢力戰爭時, 首先考慮到的, 是戰區分散, 以致影響勢力戰爭的作戰規模。基於每一個勢力戰爭星系沒有甚麼差別, 要刷 LP 最佳方式就是避免紛爭, 自己縮在一個遠離敵人的星系刷就是了。這使勢力戰爭更像一個自己一角繞圈圈的遊戲而不是一個激烈競爭的玩法。除此之外, 對於剛加入勢力戰爭的新玩家, 他們在沒有加入任何組織之前, 很難明白到甚麼星系是重要的, 勢力戰爭有甚麼目標。

有見及此, CCP 設計了新的 Frontlines (前線星系) 。前線星系旨令玩家承擔更多風險時增加獎勵, 還使玩家能更緊密地聯繫在一起, 以增加直接戰鬥的可能。

前線星系有助於塑造戰區, 隨著星系易手, 玩家可以非常清楚地看到雙方勢力在整個戰爭中的進展。

新系統下勢力戰爭星系會有不同類型:

- Frontline (前線) : 鄰近敵方星系。前線星系有着最高的獎勵, 獨特的作戰據點, 及最短的佔領時間。
- Command Operations (指揮) : 鄰近己方前線星系。指揮星系作為支援派遣部隊往前線作戰。獎勵程度中等, 與目前一般星系獎勵程度相約。
- Rearguard (後衛) : 不鄰近敵方及前線的星系。這些星系只有少數作戰據點刷新, LP 獎勵亦較少。可是對於希望開拓新前線的團體, 這些星系仍可以以較慢的速度被佔領。

不同星系將會提供不同機會及不同作戰目標, 供玩家們挑戰並為其勢力推進及佔領。有關新作戰目標的內容請關注後續公佈。

===== 重塑作戰據點 =====

作戰據點於勢力戰爭中扮演重要角色, 據點作為太空中爭奪的目標, 吸引玩家佔領, 賺取LP, 以及引起紛爭。CCP 正更新目前作戰據點的內容, 引入更多種類的據點。而為了令玩家能更易明白據點的種類, CCP 將更新據點的命名方式。

新的命名方式旨在清晰顯示甚麼艦船能夠進入這些據點。命名由以下三個元素組成:

- 等級 / 大小 : 甚麼噸位的艦船能夠進入
- NVY : 海軍的簡稱。代表據點只容許 T1 及 海軍艦船進入 (海盜艦船, T2, T3 則不能進入)
- ADV : 高級的簡稱。代表據點容許 T2 及海盜勢力艦船進入。
- 數字 : 代表據點獎勵隨玩家人數擴展的上限。

結合起來就如, Medium NVY-5, 代表據點只容許 T1 或海軍, 最大為巡洋級的艦船進入。最大獎勵倍數為 5 名玩家。

新T1/海軍限制的據點, 以及前線星系的引入, 將有助小團隊玩家參與勢力戰爭活動。

據點獎勵亦有調整, 大型據點會有更豐厚的獎勵, 而同時確保較小型據點不至於成為雞肋。前線星系的據點獎勵亦有更高的人數上限, 以吸引玩家組成小團隊作戰。

===== 優勢系統 =====

佔領一個星系不僅僅只靠武力。目前勢力戰爭並沒有好好運用各種遊戲內容，如勢力需要後勤資源的補給；打撈戰場以補給物資；隨形勢改動補給路線；適時為其勢力作廣告宣傳等等。

Advantage System (優勢系統) 的引入旨在令玩家在另一層面支援勢力戰爭的進行。

各支援行動將為此星系獲得「優勢點數」。這並不是一個簡單的將進度條填滿。一個星系的「優勢加成」取決於敵我雙方勢力在此星系的「優勢點數」之差。

「優勢加成」會影響星系作戰所獲得的勝利點數。優勢系統的引入容許各種新的作戰目標添加至勢力戰爭, 而不需要重新發展一個新系統。

===== 敍事故事 & 勢力戰爭 =====

新的優勢系統已出現於首章敍事故事中, 亦將成為未來勢力戰爭更新的一部份。玩家們或許注意到不同帝國領導人正作出號召, 某些玩家正在探索和破譯散佈在新伊甸各處的線索, 以窺探未來事件進展。CCP 希望以不同敍事故事的發展, 讓玩家感受到宇宙正一步一步改變, 玩家亦能參與其中。

首章敍事故事的細節未來會再作公佈, 但如果玩家希望追踪各勢力的最新消息, 體驗宇宙故事的發展, 甚至預估最終對 EVE 各勢力戰爭的影響。可以留意 twitter #NewEdenNews。
