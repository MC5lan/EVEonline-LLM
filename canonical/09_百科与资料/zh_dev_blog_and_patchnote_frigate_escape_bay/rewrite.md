# zh_dev_blog_and_patchnote_frigate_escape_bay

------------------------------------------------------

## 要点

- -------------------------------------------------------\\原文鏈接: Frigate Escape Bay is Coming \\論壇討論帖: 视角传媒 The Scope > 版本更新日志 Patch Notes > 護衛艦逃生艇
- 所有戰列艦均配備一個護衛艦逃生倉，一個特殊艦船倉庫只能攜帶一艘已裝配好的護衛艦。在該戰列艦被摧毀時，玩家將不再以太空倉彈射離開，而是直接轉移至該艘護衛艦繼續作戰。
- 護衛艦逃生倉可存放以下護衛艦： - 所有 T1 護衛艦 - 突擊艦 - 電子攻擊艦 - 後勤護衛艦
- 這調整將會改變現時戰列艦的作戰，為狡猾的玩家提供更新穎的戰術。也讓玩家有機會更長地逗留於作戰中，除非你是打算駕駛這艘護衛艦然後把隊友都賣了。
