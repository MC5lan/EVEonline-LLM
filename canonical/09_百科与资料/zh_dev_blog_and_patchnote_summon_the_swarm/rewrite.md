# zh_dev_blog_and_patchnote_summon_the_swarm

請準備好迎接新的旗艦遊戲內容。CONCORD Rogue Analysis Beacon 是一個移動式部署裝置, 供玩家使用以幫助研究近期自由無人機侵略行徑加劇的原因。

## 要点

- 玩家可攜帶此部署裝置至 低安 或 0.0 地區錨定部署, 裝置部署後將會嘗試掃描週遭地區自由無人機的威脅數據。裝置掃描完成後, 玩家將可以獲得豐厚的獎勵。但請注意, 本地或許會出現自由無人機, 他們會嘗試在裝置收集到任何情報前摧毀裝置。
- CONCORD Rogue Analysis Beacon 可以由任何艦船上部署, 但需要與特定艦船連結才能支持其運作 : 即 無畏艦, 航空母艦, 超級航空母艦, 泰坦。在裝置部署啟動期間, 裝置將會由所連結的艦船上轉移部份能源輸出, 使其在期間內不能移動。裝置啟動完成後, 連結的艦船將恢復正常航行能力。裝置啟動後將會廣播信號, 吸引自由無人機成群結隊前來。
