# 加达里众合国

====== 加达里合众国 ======加达里合众国是一个彻头彻尾的资本主义国家。整个国家由八个大军团拥有和掌控，总共拥有超过90%的国家资产。因此每个加达里居民一出生就被错综复杂的责任和义务网络穿梭缭绕着。

====== 构成概述 ======加达里合众国是军团资本主义最彻底的体现。国内有八个大军团，总共拥有超过90%的国家资产。每个军团都是由数以千计的不同规模、不同领域的公司组成，从简单的矿业公司到强大的警察部队都涵盖其中。加达里并没有独立统一的政府，每个军团统治着自己的领土，就像他们自己的王国一样，军团之间互不干涉。对于更高级的事物上，比如对其他帝国的外交政策，由八个主要军团的CEO组成的董事会拥有最高权威。董事会同样确保国内社会基层的安全，并处理军团间的所有纠纷。
====== 八大军团 ======就是：卡拉吉塔军团，斯库维塔军团，纳基维军团，异株湖军团，维克米军团，三岛军团，CBD社团以及莱戴军团。

以下是其中三个的简介，但在这里你可看到所有军团的详细情况。

===== 历史 =====

===== 盖伦特—加达里大战：初期 =====2个世纪前，盖伦特联邦刚刚建立的时候，加达里集团已经羽翼渐丰了。尽管还没有现在那么强大，但是当时加达里经济早已遥遥领先。

大约在盖伦特联邦成立300年的时候，盖伦特和加达里联合发现星门跳跃技术不久，加达里集团独自开始在他们自己的星系内探索和殖民。就是这些盖伦特不为所知的殖民地成为了他们之间破裂的细痕，导致了后来两国的决裂和种族大战。

事情起源于一艘盖伦特侦查舰无意发现了加达里一处隐蔽的殖民地。联邦参议院注意到了这件事，开始全力调查追究，试图把所有属于加达里的隐藏殖民地迅速地纳入联邦的管辖范围。对于联邦的贪得无厌，加达里人无法忍受，怨声四起。对于加达里来说这是个简单的选择，要么永远失去他们的统治权要么立即抵抗，夺回他们的领地。他们选择了后者。

让局势一开始就变的剑拔弩张的是加达里首星。盖伦特和加达里的首星位于同一个星系，这使得盖伦特相当紧张，因为相当部分的盖伦特人居住在加达里首星上。由于上一次的失误，他们更加强保护跳跃星门以及他们隐藏的殖民地，这些殖民地上的基地是当时加达里军事基础组织的核心。而同时，盖伦特已经把舰队开进了加达里首星周围的轨道，以此阻隔行星。

接下来的几天双方陷入僵持。加达里人看似静静地守在星门旁，盖伦特人则争论着如何寻找一个最佳和平协议的方式。加达里人在他们的首星上却一刻也没有闲着。他们无法再容忍盖伦特人的阻隔行为，一些小型游击战很快上升为大型对抗战。最终行星上的盖伦特人不得不为他们的优柔寡断付出代价。

在加达里游击队破坏了盖伦特的水下城市“碧海明珠”的玻璃圆顶后，事态起了决定性的变化，50多万人在此事件中丧生。从那以后，一场浩大的血腥战争不可避免的爆发了——联邦为了报复立即组织力量对加达里首星进攻，开始一系列轨道轰炸。加达里人不得不撤退到山区和森林里，他们的抵抗力随着时间的流逝日益衰弱。剩下的问题就是：新成立的加达里合众国会怎样进行反攻呢？

===== 盖伦特—加达里大战：无人机出世与战争的终幕 =====

第一阶段那惨绝人寰的战争在两个种族间燃起仇恨的熊熊烈火，战争带给两个种族极大的苦难，和平希望渺茫。随着加达里首星难民地迁入，加达里的实力与日俱增，而与此同时盖伦特独裁政权倒台，举国上下一片混乱。加达里发动了对联邦的一系列突袭，使得盖伦特联邦那些迟缓、笨重战舰顾此失彼、疲于奔命。但是联邦的力量仍然是加达里无法匹敌的，尽管后者取得了军事上的局部战术成功，但除了打击盖伦特的士气民心，提升己方的士气以外，在其它方面并没有实质性的收获。

一段时间之后，加达里的意图便逐渐明朗，如果联邦愿意让加达里首星脱离联邦并承认新建立的加达里国家主权，他们就乐于签署和平协议。然而，基于两点原因盖伦特无法答应这些要求：其一，他们不愿意看到一个主权国家诞生在联邦境内，也不愿意迁徙加达里首星上的数目庞大的众多联邦人口；其二，盖伦特人并不是联邦中的唯一成员，假使他们同意让加达里脱离联邦，那么对于印塔基和马纳尔来说，联邦对这两个成员经济和政治上的权威将会降低，这很可能导致整个社会陷入动荡的境地。盖伦特人不得不将加达里视为联邦的背叛者，并竭力使得他们回归联邦，甚至不择手段。

联邦曾一度只能坐视加达里肆无忌惮地重创盖伦特的舰队，任由加达里鱼肉自己最偏远的几个行省。加达里日益甚嚣尘上，每隔数月他们的轻型攻击舰便会有新的改进，这让联邦束手无策。对于许多盖伦特人而言，他们认为除非加达里的要求得到联邦的允诺，不然他们的魔爪迟早会肆虐到联邦的每个角落。盖伦特所做的一切都仿佛是徒劳的，他们尝试制造的轻型攻击舰是彻头彻尾的失败品，静态防御设施诸如地雷和岗哨火炮只能勉强保护空间设备。看起来每次盖伦特一方拥有了先进、迅捷而强力的武器，加达里一方就会研制出更为出色的武器与其对抗。

最终，战局由于静态防御武器的改进而开始扭转。盖伦特在战争中一直使用地雷，但收效甚微，然而当时机械技术的大发展让历久弥新的地雷逐渐蜕变为一种杀伤力极大的致命武器。第一代无人机比地雷稍大，拥有触发式爆炸装置和一定的移动能力，很快它们逐渐发展成为一种可匹敌轻型攻击舰的有力武器。无人机的制造成本更为低廉并且不需要训练有素的飞行员驾驶，这意味着单人攻击舰辉煌的时代以近黄昏。无人机扭转了战局，而这次加达里竟然一反常态地处于下风，为应对这种新型武器而忙得焦头烂额。但加达里仍然很快想到了办法，他们对飞船稍做升级，增加飞船的防御盾和其它武器，并称之为护卫舰。起初，舰上需要有额外的飞行员，但几年后加达里从朱庇特人那里获取了逃生舱技术，大部分的战舰飞行员又重新恢复到一个人。

大战在双联星系伊恩－奥斯塔附近展开。盖伦特一方凭借新型的无人机，加达里一方则拥有刚刚改良的护卫舰，双方都感到胜券在握，于是便倾其所有、孤注一掷投入战斗。EVE历史上一场旷古迄今的战役拉开了序幕。就战争的惨烈和规模而言，只有艾玛和朱庇特之间的瓦'阿提欧斯战役能与之相提并论。伊恩－奥斯塔战役的战火持续燃烧了整整一天。在连续激战了15小时后，加达里堂而皇之但不失尊严地撤出战场。盖伦特人声称他们仍然坚守在战场上因而是最后的胜利者，而加达里则宣称对盖伦特造成了更大的损失，这比盖伦特人自认的胜负逻辑要客观地多，因此他们才应该是胜利者。无论如何，战斗对双方都没有取得预期的决定性胜利，而且胜负的界线永远无法划分。

凭借新型护卫舰加达里抑制住了联邦咄咄进逼的进攻势头，不久以后，战争再次陷入僵局。慢慢地，大多数人的生活重归平静，这场战争仿佛是远方的雷暴，与人毫不相干，只是偶尔会让人为之惶惶。双方无一愿意坐下来谈判以重新换来和平，生怕这是向对方示弱的标志，而双方成长起来的年轻一代却愿意致力于和平，因而这场战争逐渐降级为小范围的边界冲突和袭击。当盖伦特人接触到艾玛帝国后——盖伦特人感到艾玛帝国对他们的威胁远大于加达里——战事终于落下帷幕。这促使他们紧急议和并草草达成和平议定。联盟承认加达里的主权独立，双方保留原有的边界地区和殖民地，只是加达里首星仍然由联邦统治。
