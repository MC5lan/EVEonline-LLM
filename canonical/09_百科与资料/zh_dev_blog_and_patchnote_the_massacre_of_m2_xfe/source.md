===== 泰坦之戰 =====

EVE (亦是電子遊戲) 歷史上最大型的戰爭已經持續了數個月, 局勢正不斷升溫。交戰雙方都派出了新伊甸中最大型的超級旗艦艦隊參戰, 隨着雙方戰線愈捱愈近, 戰鬥亦越來越血腥, 越來越多大型的戰鬥。每一場戰鬥對於雙方是否能在是次戰役中取勝, 對成員的士氣等都變得越來越關鍵。

2020年12月30日。隨着雙方對彼此的步步進逼, 最終爆發了新伊甸史上最大型的戰鬥。PAPI 部隊持續對 Imperium 總部 Delve 星域的進軍, 並開始對 M2-XFE 這座看似"沒甚麼關系" 的 Keepstar 發攻勢, 在沒有甚麼抵抗下拆除了建築的護盾, 但當建築到了裝甲層時, Imperium 的超級旗艦艦隊作出了回應。

一艘 Imperium 的截擊艦對 M2-XFE 的誘導干擾器作出了攻擊, 這爲 Imperium 提供了投送窗口, 在誘導干擾器完成修復前, Imperium 可以投送旗艦進場支援建築。及後又有幾艘 Imperium 成員多次對誘導干擾器作出了攻擊, 爲 Imperium 持續打開了部隊投送的窗口。然而進攻方也利用這一時機投送了他們支援部隊, 雙方都希望在艦隊數量上取得優勢。

在 GMT 22:33, PAPI 艦隊移動至 Keepstar 下方的位置, 並等待着 Imperium 艦隊是否會脫離 Keepstar 的繫泊並交戰。當 PAPI 向 Keepstar 發動攻擊的同時, Imperium 艦隊亦脫繫泊狀態並作出還擊。接下來的事大家都知道了, EVE 歷史上規模最大的戰鬥。

戰鬥持續了約 14小時, 雙方都陸續集火, 一艘接着一艘地清除對方的泰坦及超級旗艦。雙方達成的擊殺旗鼓相當。這場作戰一直持續到第二天伺服器維護的時間，PAPI 艦隊保持離線狀態。讓這場戰鬥在成堆泰坦殘骸中落幕。

===== 最終數字 =====

ISK 損失 : 29,111,604,784,863被摧毀泰坦 : 257 艘被摧毀艦船 : 3,404 艘折合 USD 總值 : $378,012(以當時PLEX平均價計算, 此數字只作是次戰事中所摧毀的價值, 並不代表真正投資的現金)

被摧毀最貴艦船 : Grencia Mars 的 Vanquisher (征服者級), 價值 381,097,221,673, 折合 USD$ 5,500。

===== 紀念碑 =====

在 M2-XFE 戰場遺址之中, 新伊甸將會樹立一座紀念碑。

設計師注: 這紀念碑最初的概念很清晰, 一座半圓形的立體模型, 兩側均有艦船準備作戰, 中間的標語上印有所有參戰玩家的紀錄。設計師希望以莊嚴宏偉的形式來代表這史詩級的戰鬥。Hallgrimskirkja (哈爾格林姆教堂) 的結構成爲了靈感對像。設計團隊建議以紀念碑亦參考 Keepstar 的形狀。於是設計師嘗試以多種不同形狀拼接設計, 在完成主體結構的設計後, 將之前草案上設計元素合併, 最終得出一個內部呈 Keepstar 形狀的半圓形紀念碑。

==== 泰場及常規艦隊的損失數目 ====

多達 1,304 艘泰場參與了作戰, 257 艘被摧毀, 摧毀率大約 20%。

==== 高峰參與人數 ====

EVE 中各戰事規模由 HED-GP, B-R 至今天正逐步增長, 雖然 M2-XFE 的戰事並沒有打破 FWST 戰事中單場戰鬥最多參與人數的紀錄, 但亦毫無疑問名列前矛。請注意此表列出了被摧毀價值。

以上圖表中部份數據由玩家們的好伙伴 Zkillboard 提供, 網站只透過 ESI 來統計相關數據, 所以數字或會與實際有所出入, 但 257 艘泰坦的擊毀數已經認證核實。

==== 泰坦的被擊毀數 (以所屬聯盟排序) ====

以泰坦擊毀數計算, 這場戰事並沒有明顯的勝方。PAPI 方合共損失 130 艘泰坦, 而 Imperium 方則損失 122 艘, 僅以 8 艘差異優於進攻方。

==== 艦船擊毀數艦船 (以噸位排序) ====

雖然因爲泰坦噸位, 火力, 價值等成爲整場戰鬥的焦點, 但戰場上並不是只有泰坦在場, 還有上千名玩家駕駛常規艦船在戰場上作戰。

===== 數字我都看矇了, 有甚麼好理解的例子? =====

讓我們除開 ISK 及 USD 價值不談, 讓我們以 EVE 世界的視角來看一下。泰坦本身是超大型武器。有多大型呢? 以 Avatar (神使級) 爲例, 其質量爲 2,400,000,000 公斤。即爲 2,645,547 美噸, 等同於 7座 帝國大廈, 長度達 14km (8.5 哩)。若墜落在行星上足以產生毀滅式的災難。

泰坦殘骸總質量 : 591,100,000,000 公斤, 已經是相當於一顆大型小行星了。比 小行星 4769 稍爲重點。可幸的是,殘骸已經被打撈用作建築紀念碑之用, 並不會對週邊行星構成威脅。

全數參戰的 1304 艘泰坦的總質量爲 : 2,999,200,000,000 公斤，比 伊卡洛斯 1566 小行星稍爲重點。伊卡洛斯 1566 是一顆具潛在威脅的小行星, 麻省理工學院曾經對此如何防範此小行星對地球的威脅作出過研究, 指出若然其運行到與地球相撞的軌道上時, 則需要以 6個 100兆噸級核彈頭應對, 然後祈禱有效。

參戰泰坦若以頭尾相接量度, 全長爲 20,538 公里。大約可以繞地球半周, 亦大約 2倍於地球直徑。就作戰規模而言, 這確實是一場超大型的戰鬥。你可以想像戰場延綿數百甚至上千公里。

以上只是一些關於大小和質量的冷知識小趣事, 還沒有觸及令人震驚的火力規模。這場戰鬥中艦船所作出的傷害量具之龐大。經粗略估算, 所有當時所發射的末日武器的總能量值相當於一顆小恆星的能量 (基於 Nuclear L 彈藥的質量, 傷害, 以及與當代核武器的比較) : 超過 1000億 TJ (1TJ = 10^12J) 的能量。

===== 戰事仍在繼續 =====

雙方的交戰還遠未落幕, 存活的 PAPI 艦隊發現自己被困在戰區上, 並開始嘗試逃離。CCP 很高興地慶祝 EVE 歷史這一驚人成就和歷史事件, 並且一如既往地期待著玩家們編織一頁又一頁的史詩故事。
