🤝- 標注爲玩家反饋或建議的調整

-----16/11

===== 探索 =====
 *再新增多2個探索據點。成功攻略這些據點將可獲得旗艦及超級旗艦製造組件。
 *AEGIS Secure Transfer Facility 會出現在 低安及蟲洞未知星系。玩家可以透過這據點去追蹤 AEGIS Secure Capital Construction Forges 的位置。
 *AEGIS Secure Capital Construction Forges 只能夠透過完成 AEGIS Secure Transfer Facility 據點才能找到。成功攻略並撤離的話, 將可以獲得超級旗艦製造組件。

===== 圖像 =====
 *爲 AIR 新手教學內容的角色加入動畫及同步其話語唇部動作。

===== 宇宙日常 =====
 *更新位於 Manarq 的 Alliance Tournament 紀念碑, 祝賀 HYDRA RELOADED 取得 ATXVII 的勝利。

===== 市場 =====
 *AEGIS Databases 移至貿易貨品欄目。

-----

-----09/11

===== 音效 =====
 *更新艦船引擎音效, 使引擎音效更會隨當前速度而變化。

===== 圖像 =====
 *調整圖像渲染的優先次序, 以確保在出站或其他場景轉換後儘快在空間場景中看到各結構和天體。

===== 探索 =====
 *加入 2個新探索據點, 未來會再添加 2個新據點。成功攻略這些據點將可獲得旗艦及超級旗艦製造組件。
 *成功攻略據點後, 可以獲得以下物品 (還有其他戰利品) : Electro-Neural Signaller (電子神經信裝置), Counter-Subversion Sensor Array (抗干擾感應陣列), Nanoscale Filter Plate (納米級過濾板), Nano Regulation Gate (納米校正閘), Meta-Molecular Combiner (分子變換合成器), 及 Enhanced Electro-Neural Signaller (加強型電子神經信裝置).
 *AEGIS Capital Ship Security Facility (AEGIS 旗艦安全設施) 會出現在 低安星系, 據點內部署了重型火力防禦的安全保險庫。若找到方法攻略這據點的話, 將獲得旗艦製造組件等獎勵。
 *Overmind Nursery Groves 會出現在 Pochven (故土) 星域, 由自由無人機防禦。掃描、打撈、隱形, 再帶着超級旗艦製造組件離開。

===== 系統 =====
 *🤝移除連結 ESS 的 PVP 計時, 改爲開火計時
 *//在上週 CCP 爲連結 ESS 帳戶加入了 PVP 計時。之後觀察到有攻擊方爲了避免在 ESS 內部引起衝突, 選擇直接離線或其他方式以加速離開 ESS 作戰泡泡。
 與 CSM 及玩家社區們討論過後, CCP 修改了連結 ESS 的機制, 現在將加入 60秒開火計時, 並不會重置玩家的 PVP 計時。//

===== 技能 =====
 *玩家可以把艦船配置拖放至技能規劃中。
 *這操作會把該配置中所有物品的所有技能需求 (包括前置技能需求) 一併填入至該技能規劃方案中。

===== 市場 =====
 *增加市場上 NPC 回購 Rogue Drone Infestation Data 的數量。

===== UI =====
 *🤝調整公司招募的數個項目
 *公司廣告中可以只選擇一個大類 PVE, PVP, 貿易&工業, 及最多四個的活動項目。
 *加入「New Pilot Focused」的勾選項目, 以標注該公司集中幫助新玩家加入 EVE。這會更好地與「New Pilot Friendly」, 即歡迎新玩家 作出區別。
 *公司只能在已勾選「New Pilot Friendly」後才能再選取「New Pilot Focused」
 *公司可以選擇最多2個活動領域。
 *下調主要活動時區的範圍至 8小時, 移除第二時區選項。
 *所有目前廣告需要在過期後作出更新。
 *🤝在兌換窗口中加入過濾及排序功能。
 *亦不會在打開窗口後預設選擇所有物品。
 *🤝加入更多幫助指示。
