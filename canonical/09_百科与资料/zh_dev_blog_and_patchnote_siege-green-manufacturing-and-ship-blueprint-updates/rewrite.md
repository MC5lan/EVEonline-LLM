# zh_dev_blog_and_patchnote_siege-green-manufacturing-and-ship-blueprint-updates

主要方案修訂爲兩方面:
 *調整2款組件的材料需求
 *Capital Core Temperature Regulator (旗艦核心溫度調節器) : Core Temperature Regulator (核心溫度調節器) 的需求再下調至 70
 *Neurolink Protection Cell (神經鏈接防護單元) : Genetic Safeguard Filter (基因保護過濾裝置

## 要点

- *修訂航空 母艦, 無畏艦, 戰力輔助艦的整體需求  *疏理三款艦船的製造需求, 以明確區分各款艦船的製造成本。價格由低至高爲 : 無畏艦 < 航空母艦 < 戰力輔助艦。
- 去年, CCP 就工業架構作出重大調整, 大多數高級艦船都添加了額外組件需求。這些新組件及材料的添加推動新伊甸更多元的活動發展, 亦給予 CCP 工具去就每一款艦船個別調整造價的能力。在此之後 CCP 一直密切監查生態系統如何就新組件的添加作出反應, 而現在, CCP 將會對艦船的材料需求進行下一階段調整。
- 是次調整是爲了:  *下調 初階行星開發材料 (PI) 的需求  *下調 勢力及海盜艦船 的材料需求  *大幅下調 無畏艦 的材料需求  *下調 其他旗艦及超級旗艦 的材料需求  *下調 旗艦及超級旗艦製造 的後勤運輸需求
