====== 玩家將能透過探索計劃新階段, 幫助對抗 COVID-19 ======

--------\\原文鏈接: Fight COVID-19 by playing EVE Online in new phase of citizen science initiative Project Discovery

</jumbotron>

15/6, 2020 - 雷克雅未克, 冰島

今天, CCP Games ames 很高興與 Massively Multiplayer Online Science (MMOS) 合作推出 Project Discovery (探索計劃) 的第三階段。

----

現在，有史以來第二大的 PLEX for GOOD 已經為 世界衛生組織 COVID-19 基金和 約翰霍普金斯大學健康安全中心（CHS）籌集了 135,550 美元。因此 Project Discovery 將著手進行一項重大計劃，以了解免疫系統對新型冠狀病毒的反應。在此之前，Project Discovery 已經開展過兩個開拓性里程碑，玩家們在2016年透過這計劃繪製了人類蛋白質圖譜，並在2017年搜尋系外行星。

----

與來自 麥吉爾大學，不列顛哥倫比亞省癌症的科學家，以及包括摩德納大學和意大利雷焦艾米利亞醫學院的免疫學教授 Dr Andrea Cossarizza在內，等前線COVID-19臨床醫生合作，玩家將能夠為這場戰鬥做出貢獻，通過分析流式細胞儀產生的數據來對抗COVID-19。流式細胞術是一種用於檢測和測量細胞的物理和化學特徵的技術，尤其是免疫系統的那些特徵，這些特徵在研究免疫系統對SARS-CoV-2感染（冠狀病毒引起COVID-19的感染）的反應中很重要。

----

玩家可以通過 EVE Online 中的 Project Discovery 的迷你遊戲互動，玩家將使用追踪工具標記出血液中的細胞群組，從而幫助科學家了解感染後不同的細胞群的數目及種類如何被改變。玩家也將因參與遊戲內容而獲得獎勵。那些登錄 EVE Online 的玩家將找到有關 Project Discovery 的詳細教程，其中包含有關如何開始幫助現實科學事業的完整細節。

----

玩家還可以在今天世界 UTC 19:00 觀看特備環節, Project Discovery遊戲玩法的 Twitch直播，慶祝由 CCP Games主辦的第三階段計劃啟動，主要參與者包括 MMOS首席執行官兼聯合創始人Attila Szantner，副教授 Jérôme Waldispühl 和 Dr. Ryan Brinkman.

----

EVE Online的創意總監 Bergur Finnabogson 指：“自從開始 Project Discovery 以來，玩家們只要團結在一起，就能帶來不可思議的影響。玩家們亦透過近期的 PLEX for GOOD 計劃不斷提醒 CCP，EVE社區是如何的與眾不同。在 Project Discovery 的第三階段中，CCP 很高興提供工具，讓我們的玩家能夠為共同的利益再次致力改善人類的福址。”

----

MMOS首席執行官兼聯合創始人 Attila Szantner 表示：“我們創建了MMOS，將科學研究和視頻遊戲連接在一起，從而獲得無縫的遊戲體驗。通過此版本的 Project Discovery，我們亦爲此計劃加添了一個新方向：展示了遊戲玩家如何組成緊急反應小組以在此危急情況下協助分析科研數據”

----

麥吉爾大學計算機科學學院副教授 Jérôme Waldispühl 說：“Project Discovery 已經改變了我們以往所認知的民間線上科學，我們很高興他們決定此敏感的時間參與了這個關鍵的項目。”

----

不列顛哥倫比亞大學醫學遺傳學，BC Cancer 傑出科學家，Ryan Brinkman博士指 :“該項目將以一種獨特的方式去挖掘 COVID-19 細胞數據，我們希望它將促進新發現，參與者產生的數據也將有助於開發下一代算法。”

----

計劃的最新進展可以在 麥吉爾大學計算機科學學院計算機科學家和生物信息學家團隊的網頁 DNApuzzles.org找到。
