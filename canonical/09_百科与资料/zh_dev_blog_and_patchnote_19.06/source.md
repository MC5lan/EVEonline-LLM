27/7

===== 圖像 =====
 *Encounter Surveillance System (事件監測裝置) 視覺效果重塑
 *重新打造其建模
 *加入週邊燈光效果, 顯示出其訪問需求距離
 *事件監測裝置建築外觀將會隨玩家訪問而有所不同
 *訪問 ESS 時的視覺效果更新
 *訪問主賞金池及儲備賞金池將不有不同訪問視覺效果
 *其視覺效果將會顯示還有多少時間才能獲得賞金代幣
 *ESS 中的躍遷干擾力場視覺效果調整, 泡泡的視覺效果會隨玩家視角的縮放距離而有所不同。
 *拉近視角時, 將會在範圍內看見較細微的干擾效果
 *拉遠視角, 會清晰顯示出泡泡的範圍邊緣

===== 探索 =====
 *Secure Commerce Commission Secure Key Storage Sites (安全商業委會員安全密鑰存儲設施) 將會在低安星系中出現。據點隱藏嚴密, 受到 SCC 的嚴密保護, 以防止任何不必要的入侵。據古斯塔斯海盜的謠言指, 這些據點都有 ESS 儲備賞金池解鎖鎖匙。
 *修改 Pochven 星域巡邏 NPC 的偏好領域。三神裔艦隊將集中出現於空間站及導管星門, EDENCOM 艦隊將出集中出現於各星體位置 (如行星)。流浪者及自由無人機將集中出現於蟲洞附近。而各勢力將會於行星, 恆星, Dazh Liminality Locus 區域交戰。剩下內容請玩家自行發掘。

===== 市場 =====
 *新伊甸所有星域市場的銷售稅減少 50%
 *經紀人費用減少 50%, 而 Advanced Broker Relations 技能效果亦有所上調, 由原本每級減少 5% 經妃人費中上調至 減少 6% (即最高 V 級技能時爲減少 80%)。

===== 任務 & NPC =====
 *Pochven 星域中各據點的獎勵將有所限制。據點獎勵的分發將如入侵據點般, 只限攻略據點中最高傷害的艦隊才能獲得據點攻略獎勵。亦只有在據點內的合資格艦隊成員才能獲得獎勵, 即 非隱形狀態, 不包括新手船/穿梭機/太空倉/Zephyr)。

===== 機制 =====
 *Encounter Surveillance System (事件監測裝置) 儲備賞金池區開放給玩家解鎖提取款項
 *儲備賞金池可透過 ESS Reserve Security key 解鎖
 *儲備賞金池解鎖後, 將每分鐘與之鏈結訪問的玩家發送賞金代幣
 *每位鏈結訪問的玩家將以賞金代幣形式獲得賞金, 可及後透過 NPC 收購訂單兌換成 ISK
 *玩家於同一時間只可以與一個賞金池鏈結訪問, 即主賞金池或儲備賞金池之一
 *推出 ESS 儲備安全鎖匙
 *鎖匙容許玩家啟動儲備賞金池賞金代幣的支付程序。不同鎖匙對應宇宙中不同的地區, 亦有解鎖時間15分鐘與45分鐘的型號之別。

===== 建築 =====
 *Defunct Encounter Surveillance System (即舊有玩家自行錨定的事件監測裝置) 將添加上 14天的降解時間, 以供遊戲去除剩下的 舊ESS 資源。

===== UI =====
 *爲事件監測裝置加添新型空間UI 介面
 *新的空間 UI 元素爲未來 EVE Online 開拓道路
 *UI 介面會按視角角度及縮放大小而變動
 *UI 元素將固定於主賞金池及儲備賞金池建模處
 *UI 將會顯示出主賞金池及儲備賞金池的相應計時
 *在艦船未滿足訪問距離時亦有標注提醒顯示
 *更新 ESS 信息面板
 *主賞金池及儲備賞金池信息均作顯示
 *在賞金池被入侵時將即時顯示
 *可點擊主賞金池及儲備賞金池信息以打開顯示入侵紀錄
 *在賞金池被入侵時, 信息面板將顯示 "Warp to" 按鈕供非ESS 區域內的星系玩家使用
 *儲備賞金池信息區加入滑鼠浮動顯示, 顯示更多信息
 *信息面板亦有簡潔模式
 *移除舊有 ESS 訪問視窗
