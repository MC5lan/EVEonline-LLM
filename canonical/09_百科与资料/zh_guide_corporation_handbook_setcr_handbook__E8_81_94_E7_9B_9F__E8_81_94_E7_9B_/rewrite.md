## 要点

- ====== 采矿 ====== - 联盟目前有公共月亮计划，并将在将来数量继续增长。 - 联盟保障新人优先采集公共月亮。 - 可以租赁月亮，获得该月亮矿石的支配权。 其他详细： - zh:rules:pve:public_moons - zh:rules:pve:moon_renting
- ====== 制造 ====== - 联盟有三处 sotiyo 超旗制造与三处 azbel 小旗舰制造与 T2tatara 化矿。 - 首都有全套 T1/T2 常规舰船、弹药与装备制造线与 T2 小化矿。
- ====== 物流 ======目前联盟在营有 4 家快递公司，其中三家联盟直属，一家个人运营。营业范围涵盖大宗小宗包船加急等各种需求。 具体营业细则： zh:services:courier:start
- ====== PAP ====== - 一般来说，每个成员每个月最低要求 3 个 PAP。其中在 SeAT 中绑定在一起的一组角色称为一个成员。 - 如果你在多个成员公司有人物，则每个公司中你所拥有的角色 PAP 总数之和均需达到最低数量要求 (3 个）。 - 不能完成基本要求的人会被公司询问或警告，长期不能完成的成员最好归结为不活跃成员并暂时移除。 - 其他详细： zh:rules:military:pap====== SRP ====== - 如果舰队有集结信息(Ping)，将给予扣除白金保险赔付的舰船总值的 70% 到 120% - 如果舰队无集结信息，但是损失来源于收割或反收割，且舰船装配合理，我们将给予扣除白金保险赔付的舰船总值的 50%。每个联盟成员每月 1B(十亿) ISK 上限额度。此类补损请求将于每月月底定时处理。
