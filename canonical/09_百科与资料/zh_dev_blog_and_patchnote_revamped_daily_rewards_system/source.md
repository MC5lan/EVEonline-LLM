# zh_dev_blog_and_patchnote_revamped_daily_rewards_system

<jumbotron>

--------

====== 重塑每日登錄獎勵 ======

-----\\原文鏈接: https://forums.eveonline.com/t/revamped-daily-rewards-system/

</jumbotron>

大家好。

很高興地宣佈 CCP 將於 5/4 大幅修改每日登錄獎勵系統。

是次更新將會調整每日登錄的獎勵內容, 以及新的 UI 介面以清晰顯示未來幾日登錄的獎勵。

-----

<fs x-large>獎勵:</fs>

首先以大家最關心的內容開始。CCP 重新設定了每日登錄的獎勵項目: 以新的永久 SKIN 取代舊有的限時 SKIN; 新式專門作爲每日登錄獎勵贈送的增效劑; 把累積一定天數後獲得的技能點獎勵調整爲每日登錄獎勵項目; 完全移除藍圖獎勵。

-----

<fs x-large>SKIN:</fs>

所有限時 SKIN 將會移除, 取而代之是數百款永久 SKIN。新系統將推出 260 款永久SKIN (多數使用 Halcyon Dawn 及 Carmine Horizon 樣式), 以及 148 款過去活動 SKIN, 如 Strikeflight Red (赤紅突擊), Frontier Safeguarder (邊境保安軍), Zakura Hansei (寒水櫻), Purity of the Throne (聖潔王座) ，等等。

新的每日登錄獎勵系統會追蹤檢查角色已經擁有那些 SKIN, 從而避免重複贈送。(基於除了舊有活動 SKIN 外, 還有一堆新款 SKIN 可以送, 而且未來還能按情況追加, 所以不會發生你所有 SKIN 都有了沒得送的問題。)

就如以往的登錄獎勵 SKIN, 這些 永久 SKIN 會在兌換至角色後自動使用。

新的 Halcyon Dawn 及 Carmine Horizon 樣式可以於文末, 或者 sisi 預覽。

-----

<fs x-large>增效劑:</fs>

舊有每日登錄贈送的增效劑都有點作用, 但它們其實是遊戲中已有型號, 而非專門爲每日登錄而設, 所以有些玩家可能早就持有一堆而不具吸引力。這些增效劑具有技能需求, 某些甚至有副作用, 往往只合適於某類遊玩領域或艦船配置, 而且其作用時效亦不太合適直接於兌換後使用。

所以 CCP 透過設計新的 Halcyon 增效劑以解決以上問題。這些增效劑會對大部份屬性提供小量加成, 代表不同類型的活動及配置都適用。新式增效劑亦不具任何技能需求及副作用, 基礎作用時效亦長達 2小時 (可透過 Biology - 生物學再作延長), 使玩家可以於方便的時候兌換, 對整個遊玩時段提供加成。

新式增效劑共有 4個款式, 每個款式有 5個級別的強度型號差別。α 玩家可以 tier 1-4 的增效劑, 而 Ω 玩家則可以獲得 tier 2-5 型號。

新的每日登錄獎勵增效劑會在兌換時自動使用, 在登錄獲得後會存放於兌換序列中 7天, 使得這些強力及多功能的增效劑不能囤積。

文末會列出新式增效劑的詳細屬性。

-----

<fs x-large>技能點</fs>

CCP 修改了新登錄獎勵系統中技能點數的分發方式。在舊系統, 視窗底部會有一欄進度條, 填滿後獲得一定數量的技能點。在玩家測試中, 這模式其實對新玩家來說過於複雜。新系統中, 玩家將會每隔幾天就會直接獲得技能點數。

新系統下獲得的總技能點數與舊系統相同 (Ω 玩家平均每 30天獲得 15萬技能點, α 玩家爲 5萬), 但將會是每隔幾天獲得一小量而並非到一個月後獲得一大罐。

爲過渡至新系統, CCP 會在更新時, 對過去一年內有登錄過的玩家, 將已經部份填充進度條內的技能點分發給玩家。

-----

<fs x-large>纖維</fs>

初階深淵纖維仍然會作爲每日登錄獎勵贈送, 但其贈送頻率將是以往的一半, 以騰出空間予新的增效劑及 SKIN。

-----

<fs x-large>UI</fs>

爲配合推出新獎勵, CCP 亦重塑了每日登錄獎勵的 UI 介面。

其中一個重要調整是新 UI 介面會清晰顯示未來 4天的獎勵內容, 以對應的圖標及標籤表達獎勵的類別, 而不再是以往的一個盒子的形式。

新 UI 介面包括目前的 UI 風格及新的 Photon UI 風格, 視乎玩家有沒有於遊戲中修改使用。

-----

希望玩家能滿意新的每日登錄獎勵, CCP 亦計劃在推出後視情況再作調整, 所以有任何想法請告訴 CCP。
