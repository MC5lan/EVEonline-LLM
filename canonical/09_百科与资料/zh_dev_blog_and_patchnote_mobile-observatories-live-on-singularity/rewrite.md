# zh_dev_blog_and_patchnote_mobile-observatories-live-on-singularity

新型移動式星系探測裝置現正在 Singularity 供大家測試。此部署裝置將讓大家能有機會於 低安 及 0.0 星系 防禦隱形艦船的侵略。裝置會定期掃描整個星系, 有機會使正在隱形的艦船解除隱形狀態, 從而能夠被作戰探測定位及捕捉。而爲防止此裝置對於活躍玩家有嚴重影響, 現有隱形裝置在啟動時會有一段短時間加成<fs small> (sisi 的設定是 15分鐘)</fs> , 以免疫移動式星系探

## 要点

- -----截至 2021/05/18, Mobile Observatory 在 sisi 的設定數值如下:  *部署時間 : 10分鐘  *裝置壽命 : 1小時40分鐘  *體積 : 100m3  *護盾/裝甲/結構量 : 5000/5000/20000。抗性：0  *與另一個 Mobile Observatory 部署最短距離 : 10km  *與 POS 部署最短距離 : 100km  *技能需求：Anchoring III
- 另外 sisi 的實際使用情況如下：  *就如誘導力場一樣全星系可見，可直接躍遷前往  *探測週期：部署完成後1次，其後每10分鐘1次  *解除隱形機率：40%，每艘艦船個別判定  *單星系部署上限：10個
