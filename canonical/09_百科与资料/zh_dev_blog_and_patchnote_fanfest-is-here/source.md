>CCP 這次把 Fanfest 分成兩篇帖子放到官網新聞中, 而 Fanfest 2天亦有不同重覆 / 相互補充的環節。把兩篇怎樣剪裁到一起都總有點違和, 於是就擺爛地把兩篇都直接譯一次好了。
另外這次也把 Keynote 摘要弄成精華放到 Bilibili。還望大家多多關注。

===== 叙事線及版本式更新 =====

未來更新步伐將會以叙事形式, 講述連續的世界故事, 讓玩家們能夠參與到事情發展當中, 爲新伊甸宇宙及新項目的發展帶來長遠影響。

未來已計劃一系列的更新內容, 以故事形式在未來數月一步一步展開, 途中讓玩家不斷探索及了解。

另外, CCP 也重新以大型版本更新方式推送新內容, 首次大型版本更新將於 2022年第 4季推出。

===== 勢力戰爭 =====

勢力戰爭一直是 EVE Online 核心故事的一環, 在過去一直都產出不少驚奇的玩家故事。而展望未來, 勢力戰爭將是 CCP 重點發展方向, 推出各種大大小小的更新及調整。

通過精心策劃的敘事故事和由玩家爲主導的事件, CCP 將以勢力戰爭作爲新內容進入 EVE 的切入點。而不少內容也會漫延到宇宙其他領域。例如建築機制, 戰區控制, 新型艦船, 裝備, 平衡調整。甚至新的玩法等。

CCP 計劃調整玩家如何宣稱自己爲某一勢力效忠。方案是推出一個新的忠誠系統, 容許玩家不需要離開現有團體而能夠參與勢力戰爭內容。

===== 前線星系 =====

CCP 計劃透過引入前線星系的概念使勢力戰爭的版圖及地理有實質意義。與敵勢力比鄰的星系將被定義爲前線星系, 遊戲中會清晰標示。前線星系將提供更豐厚的活動獎勵, 以鼓勵玩家於前線星系作戰, 或未來會有更多前線星系特有遊戲內容。

===== 展示身份和地位 =====

玩家將可以在其以新貨幣, InterBus 代幣去爲艦船等上添加聯盟圖標, 全息影像等方式去展示自己的聲望, 擊殺標記, 也包括建築SKIN 及其他自訂義元素。

InterBus 代幣 - iBc 只能透過遊戲活動中獲取。iBc 不能夠交易給其他玩家, 不能出售, 也不能兌換成其他貨幣, PLEX, ISK 等。

===== 改進新手體驗 =====

引領新玩家加入 EVE Online 是持續及長遠的工作, 未來有不少新項目推出。

新 NPE 故事, 以探索爲主的內容將於 2022年秋冬時推出, 爲新玩家體驗項目的第三章節。

另外 CCP 亦重塑教學代理人體驗, 以及引入新的 AIR 職業規劃項目, 以幫助新玩家認識 EVE 中不同領域的內容。

技能規劃也有重大更新, 包括引入更多認證計劃及容許公司創建公司規劃等。

未來對老玩家來說也有不少新項目, 包括重新調整所有技能, 移除角色屬性值, 重塑學習植入體等。

===== 歡迎西班牙玩家 =====

爲讓新的和現有的西班牙語玩家提供更適合他們語言的體驗, EVE 客戶端將提供西班牙語的支援。首批試版將於9月份推出, 並在 2022年冬季時推出正式版本。

===== 太空中的試算表 =====

CCP 將與 Microsoft 公司合作, 爲玩家帶來更便捷的數據處理體驗。未來 CCP 將會推出新的 Excel 擴展組件, 讓玩家能夠直接把 EVE 數據添加至 Excel 中。

===== 克隆飛行員編年史 : 第二部 =====

克隆飛行員編年史的第二章漫畫經已推出, 免費下載。, 並在今年年尾推出連同剩下兩章一起集結推出精裝版書本。

===== EVE 現代化並邁向未來 =====

邁向未來第三個十年, CCP 將繼續改善 UI 體驗。Photon UI 計劃正在進行中, 其他 UI 元素也有不同的研究項目, 例如同時打開數款總覽視窗。

視覺及聽覺體驗也是改進工作重要的一環。未來已計劃數項不同的視覺美術升級項目, 包括高解析度星雲背景, 重塑的細節層次系統, 新粒子着色效果, 新停靠動畫等, 以確保新伊甸一直保持一流的視覺體驗。另外, 技術上如 Fidelity FX 等新技術的加入, 將有效提升中低配置電腦的體驗。

===== 更多有關勢力戰爭 =====

勢力戰爭的調整還包括建築機制的改善, 戰區控制, 艦船及艦隊平衡調整, 勢力戰爭據點調整等。

這些調整的目標是創建更有義義, 動態的勢力戰爭版圖, 獎勵那些爲其勢力作戰的玩家, 讓玩家在勢力戰爭的中的選擇更有意義, 以推動玩家參與各項勢力戰爭的活動, 使玩家參與由其自己推進的勢力戰爭故事。

CCP 正在確保所有新的勢力戰爭元素都會互相配合, 在平衡調整、風險和回報方面都做了大量的研究。CCP 首要考慮是玩家之間的互動, 使新的勢力戰爭框架能讓不同的遊戲風格和玩家的玩家都式能聚集在一起, 提供真正令人難忘和獨特的體驗。

CCP 也引入新系統讓玩家能夠更容易選擇效忠的勢力。玩家將可以在不需要離開現有團體的情況下對某勢力效忠。新系統會與聲望不同, 但會有關連。

NPC 勢力會有自己的發展方向, 有不同的目標, 或許會影響勢力戰爭的形勢發展。玩家在幫助其勢力達成目標會有獎勵, 而該勢力是否能完成目標完全基於玩家的參與。

最終, 新的勢力戰爭系統將讓玩家透過效力其勢力, 努力達成勢力目標來分享勢力成就獎勵。因此，準備好與你所選擇的帝國作戰（未來甚至可以是海盜勢力）。

===== 動態前線 =====

目前勢力戰爭版圖共有 180個星系, 但每一個星系玩起來其實沒有甚麼分別。新的前線星系將清晰標示於勢力戰爭中。玩家在前線星系作戰將有更豐厚獎勵, 攻略前線星系需要的時間也較短, 未來甚至有前線星系特有內容。

===== 勢力目標 =====

每一個勢力會有自己的發展方向, 並會發佈不同的作戰目標。目標的類型會隨叙事發展而不同, 但達成條件會非常清晰。協助勢力達成目標的玩家將獲得豐厚獎勵。

於勢力戰爭中加入不同的作戰目標, 將使更多不同玩家都能參與勢力戰爭當中。更多的玩家加入讓勢力戰爭有更多的互動, 反過來又能讓更多新目標, 新活動的推出。

相關開發工作正在進行中, CCP 在探索更多不同勢力戰爭目標包括戰區運輸, 戰場打撈, 破譯, 滲透等活動目標。

===== 建築平衡 =====

建築機制也有不少調整, 集中於鼓勵更多的衝突。未來調整會調整避免防禦方能瞬間重新部署新的 FLEX 建築。以確保進攻方在成功攻略後能確實打開進攻窗口。旗艦級艦船的重新繫泊時間也會作出匹配其 HP 量的調整。還有是圍繞跳躍星門的進攻及反擊機制。POS 系統的退役工作將會繼續, 以推出有限度服務及容量的前哨基地來進一步取代剩下的 POS 功能。

===== 叙事式故事 =====

EVE 將加入新的叙事式故事線。每一條故事線都是一段緊湊的事情發展, 而玩家在當中扮演重要角色, 對事件故事有重大影響。

每段故事會有源源不斷的事件和內容驅動事情走向, 最終迎來高潮, 揭示新伊甸的重大變化。

爲提供最佳的故事, CCP 將採用在採用以敘事驅動設計的新方法。讓玩家在盡可能多的位置參與故事發展, 並在新伊甸留下永久影響。這意味著玩家的決定、行動和忠誠都會影響結局。許多新功能也將通過敘事方式引入, 爲玩家帶來更有意義的陣營歸屬感。

總的來說, 玩家將成爲新伊甸未來的重要的一環。

===== 大型版本更新回歸 =====

CCP 將重新引人大型版本式更新。展望未來, 版本式更新將爲 EVE 帶來重大內容變動。更新將包含以沉浸式故事、新功能、重大技術改革、藝術和音頻增強等重要內容。但與過往不同的是, 在版本更新的間隔仍然會持續作常規內容更新, 季節活動, 挑戰, 故事發展, 平衡調整等。此新式的版本更新將預定在 2022年第4季推出。

===== 裝飾與 InterBus 代幣 =====

新的紋章類系統讓玩家能夠以圖標, 視覺特效, 全息影像等, 把自己的成就, 聲望, 擊殺標記等向別人展示。玩家可以透過完成遊戲活動賺取 InterBus 代幣購買相關物品。這些活動會以簡單的日常活動形式, 活動形式, 或其他更具挑戰的形式讓玩家完成。大部份活動內容都是以玩家之間日常社交活動爲主。

爲配合新的裝飾內容, 裝配視窗也會有相應調整。

CCP 希望玩家之間能夠建立強大而健康發展的公司組織, 爲組成員有大量的目標和活動。同時也會配合提供更多工具以支援公司組織招募, 培訓和留住玩家們。

CCP 也想藉能對 InterBus 代幣徵稅而簡化他們的管理工作。除此之外, 也爲公司管理提供工具, 對兩款活動徵稅以簡化日常的管理工作, 分別是就成員獲得的 LP 徵稅, 及就成員在市場的交易徵稅。配合與 Microsoft 合作推出的擴展組件, 減輕公司管理的管理壓力。

===== 由玩家幫助玩家 =====

CCP 將推出一項新計劃, 讓玩家捐贈物品給予其他玩家。捐贈物品可以獲得 InterBus 代幣作爲獎勵, 解鎖更多裝飾式物品以展示自己的身份或聯盟地位。這計劃使得 EVE 的日常獎勵及活動也融入 EVE 玩家驅動型的經濟, 並提供更多參與經濟和獲得獎勵的途徑。

===== 其他小改善 =====

其他不同範籌內容也會持續改善, 包括各類艦船的平衡調整 (例如海軍艦船), NPC 空間站遠距離克隆冷卻時間, 星圖閱讀體驗, 針對新手玩家的惡意攻擊行爲等。

===== 結語 =====

所有這些新的更新和功能都專注於讓 EVE 更像一個活生生的在線世界, 將塑造宇宙的玩家聯合起來, 透過勢力戰爭和敘事故事的影響, 讓新伊甸作為一個充滿活力的大都市。CCP 將繼續爲玩家帶來更多內容、更多體驗和更多遊玩方式。希望你們令人驚嘆及多元化的玩家們能夠在彼此 EVE 的每一刻中獲得更多。
