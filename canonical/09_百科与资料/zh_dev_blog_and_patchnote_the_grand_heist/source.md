# zh_dev_blog_and_patchnote_the_grand_heist

--------

====== ESS 大搶劫 ======

-----\\原文鏈接: https://www.eveonline.com/news/view/the-grand-heist

</jumbotron>

大家好,

是時侯叫上小伙伴們一起去搶劫 ESS 了。
在去年新的動態賞金系統引入至 0.0 及低安星系, 0.0 星系的 Encounter Surveillance System (事件監測系統) 亦重新調整。這兩個系統一起運作, 於不同星系之間產生各種衝突及平衡不同危險地區的財富。在這兩系統推出後, CCP 按照運作情況及玩家意見作出了數次調整。

與此同時, 儲備賞金池的累積金額一直上漲, 等待着玩家將之開啟。

以下是 the Grand Heist 更新的簡述要點:
 *期待已久的 ESS 儲備賞金池解鎖鎖匙推出
 *鎖匙可以於低安星系新的據點中獲得
 *目前儲備賞金池累積總額已高達 20,000,000,000,000 ISK

-----

<fs x-large>儲備賞金池</fs>

在玩家每次獲得賞金獎勵時, 會有一部份賞金被撥入儲備賞金池, 玩家必需以新的 Secure Commerce Commission (安全商業委員會) 授權鎖匙才能訪問。在以正確鎖匙訪問 ESS 時, 儲備賞金區將會解鎖, 在其 10km 內的艦船都能夠訪問儲備賞金區。當艦船與儲備賞金池鏈接時, 儲備賞金池會每分鐘轉移一定額量的賞金至玩家貨倉, 直至儲備賞金池重新鎖上。

儲備賞金池鎖匙總共有 8 款, 每一款鎖匙都會標明其所對應的宇宙區域及其解鎖儲備賞金池的時限。賞金的轉移速度會隨鏈接時間慢慢上升, 到達上限後會下降直至解鎖時限完結時完全歸0。

請注意入侵儲備賞金池將會產生一個全星域的警報, 所以一個好的大盜應該作好規劃以確保他能夠在解鎖時間內都停留在鏈接區域, 避免「他應得的錢錢」被巡邏的艦隊搶走。

要獲得此儲備賞金池的鎖匙, 當然不是簡單地向 SCC 爸爸伸手拿。玩家需要在低安星系中找尋 SCC 的鎖匙儲存據點, 而這些據點中保證能獲得鎖匙。進入相關據點有一定的艦船數量及噸位限制, 在設定上會確保有耐心及技巧的玩家將能獲得這些鎖匙。

-----

<fs x-large>ESS 體驗重塑</fs>

CCP 將重新打造 ESS 的外觀及使用體驗。

ESS 的大小及外觀將重新構造, 玩家可以從上圖中, ESS 邊上的一艘 Vargur (惡狼級) 對比一下。而 ESS 的外觀亦會隨玩家訪問 ESS 及訪問時間而有所不同展現。

根據玩家們的反饋, ESS 將會用上新的躍遷干擾泡泡視覺效果。泡泡效果會按照玩家視角範圍及縮放大小而調節其可視程度, 以更容易看見 ESS 的操作及對應 UI 介面。

艦船入侵 ESS 的時候, 兩者之間會有新的鏈接視覺效果。而在 ISK 錢幣被轉移到艦船貨倉那一刻時亦會有特別效果。

最後, ESS 附近亦會有新的週邊照明燈以清晰展示其 10km 的訪問距離。

-----

<fs x-large>訪問 ESS</fs>

在觀看玩家們入侵 ESS 主賞金池同時迎擊敵人的影片亦幫助 CCP 發現能夠在這次更新中改善的地方。

訪問 ESS 的窗口介面將會移除, 取而代之的是新的操作 UI 提示。結合新的 ESS 建築結構, 對應的 UI 將直接套用在 ESS 對應的賞金池之上, 顯示其狀態。

在入侵主賞金池時, 主賞金池區將會有一個計時器以圖像及數子形式包圍顯示其訪問需時，而這計時器是在 ESS 附近都可見, 不論是否在訪問距離之內。

而入侵儲備賞金池的顯示形式亦相約, 對應的 UI 會顯示其訪問剩餘時間及下一批錢幣轉移倒數。兩個賞金池有對應的計時器顏色, 藍的是主賞金池, 橙的是儲備賞金池。

目前 ESS 視窗將可以在星系中任何位置中查看, 玩家可隨時得知星系 ESS 賞金池的狀態。CCP 把部份信息移至至新的信息顯示介面。

對各賞金池的入侵行徑都會即時反映於此信息介面中。對主賞池來說, 介面上將會顯示入侵者的頭像；對儲備賞金池來說, 則會顯示當前有多少玩家正鏈接至儲備賞金池, 及當期所支付的金額。

-----

<fs x-large>結語</fs>

將如此豐厚的儲備賞金池鎖匙交到玩家手上令人非常興奮, 而看着到底誰把手沾到這數 T 的賞金池亦同樣令人熱切期待。實施完美的搶劫需要仔細的計劃和執行技巧, CCP 亦很期待新伊甸園的第一次儲備銀行搶劫案是如何發生的。

而另外這也是第一步 CCP 把舊有的 UI 介面轉移至新的 空間介面, 這將會推動 EVE 走向更現代的宇宙互動模式。

最後要通知玩家們, 仍然持有舊式 ESS 的玩家請留意, 舊式 ESS 回收計劃將於此次更新後終止。而所有仍然部署在太空的舊式 ESS 都會加上一個 14天的瓦解壽命。

The Grand Heist 更新將計劃在 7月下旬推出。
