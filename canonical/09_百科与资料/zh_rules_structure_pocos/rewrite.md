# zh_rules_structure_pocos

====== 天钩等建筑 ======
- 有关能量和劳动力的天钩归属联盟。
- 试剂天钩也属于联盟。
- 任何天钩的税率都不能高于 0.2%，包括白名、浅蓝与深蓝声望。
- 如果联盟无法联系上拥有这些违反规则天钩的公司，天钩将被强制拆除。
====== 天钩盗窃规则 ======
- 禁止盗窃非本人持有的天沟，
- 拥有访问权限（通过该天沟上的ACL权限确认）的成员可以获得资源

## 要点

- - 任何公司都可以拥有行星海关。 - 如果联盟需要回购海关，联盟会支付相应价格。 - 任何海关的税率都不能高于 0.2%，包括白名、浅蓝与深蓝声望。 - 高于税率上限且无法沟通的公司，海关会被强制移除。
- ====== 自动钻探 ====== - 联盟对目前所有的私人钻机，暂时不做其他要求，但联盟随时都可根据需求调整赎买回收。
- ====== 雇佣兵巢穴 ====== - 个人不可以私自拆毁友方巢穴，已达到自己占领巢穴的目的，若经查实，需三倍赔付SRP
- - FRT（包括F.A.X和FRTU）不可以去租地（血脉特纳）、对舞、黑渊等非联盟活动领地内铆钉巢穴，若经查实需要即可拆除巢穴
- - 任何对天钩劳动力产出造成负面影响，但未导致升级离线的雇佣兵巢穴，所有者须在三天内对其进行维护，否则其将被移除。 - 持有雇佣兵巢穴的成员必须提前计划好对巢穴的工作，有责任了解它什么时候会进入无政府状态产生负面影响，并及时处理，也有责任随着CCP的版本更替改变计划以避免负面影响。 - 如果您是巢穴所有者，请不要跳过MTO。 这可能会导致巢穴失去劳动力无法修复。 - 如果你要占领一个巢穴，请尽量在占领巢穴之前截图，以防日后出现问题。 (方法是前往天钩，进入天钩办公室）。
