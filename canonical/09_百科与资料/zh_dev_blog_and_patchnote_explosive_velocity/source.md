====== 爆炸速度 ======

--------\\原文鏈接: Explosive velocity new update

</jumbotron>

大家好。

作爲 Phoenix 篇內容之一, Explosive Velocity 項目將於 24/11 更新, 對魚雷的傷害發揮作出調整, 亦會對 無畏艦船體 及 Griffin Navy Issue (獅鷲級海軍型) 作出調整。

<fs small>(官網沒有寫明調整的數值, 那只好去 Sisi 挖一下了, 最終調整值請留意當日 patch note 爲準)</fs>

-----

超大型魚雷的傷害, 爆炸速度, 飛行速度將會上調, 而其他魚雷則會有爆炸速度及飛行速度的上調, 爆炸半徑的下調。這將影響一系列相關艦船的表現, 例如 Phoenix (鳳凰級), Raven (烏鴉級), Typhoon (颱風級) 等。

XL Torpedo (超大型魚雷):
 *飛行速度 : +20%
 *傷害 : +10%
 *爆炸速度 : +20%

Torpedo (魚雷), 其他型號 :
 *爆炸半徑 : -10%
 *爆炸速度 : +10%
 *飛行速度 : +20%
 *最大飛行時間 : +20%

-----

而說起 Phoenix (鳳凰級), 作爲本次更新主題的同名艦船, 其 能量柵格 及 CPU 輸出將會上調, 容許 Phoenix 能更具彈性地使用各高槽裝備, 同時又能兼具防禦及魚雷的使用。
 *能量柵格 : 550000 (+50000)
 *CPU : 990 (+25)

-----

Moros (莫洛級) 在這次 Explosive Velocity 更新中也會有所調整, 在其 -1 中槽 及 +1 低槽 的調整下, 使 Moros 能獲得更多傷害及防禦性能, 在與其他無畏艦對比時更具競爭力。
 *中槽 : 4 (-1)
 *低槽 : 8 (+1)

-----

Griffin Navy Issue (獅鷲級海軍型) 亦有所調整, 艦船將會更偏向爲 ECM 無人機平台。艦船加成加入 電子無人機干擾時間加成, 額外的無人機帶寬 以及 無人機掛倉容量。而另一方面其無人機傷害, 血量, 控制距離亦會因而有所下調。
 *原本的 : +20% ECM 干擾器干擾強度加成 修改爲 +10% ECM 無人機干擾時間
 *兩項 ECM 干擾器的特有加成移除, 修改爲 :
 *-85% 無人機傷害
 *-50% 無人機血量, 控制距離
 *艦船數值 :
 *無人機掛倉 : 35 (+30)
 *無人機帶寬 : 25 (+20)

-----

另一方面, 因爲魚雷的調整會同時同樣使用魚雷的 Stealth Bombers (隱形轟炸艦) 也有影響, 所以 Stealth Bombers 的魚雷飛行速度加成將會有所下調, 並移除其爆炸速度的加成。
 *移除魚雷爆炸速度加成
 *原本 +20% 魚雷最大速度加成 修改爲 +15% 魚雷最大速度加成 (-5%)
