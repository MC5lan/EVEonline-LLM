# zh_dev_blog_and_patchnote_explosive_velocity

--------\\原文鏈接: Explosive velocity new update

## 要点

- 作爲 Phoenix 篇內容之一, Explosive Velocity 項目將於 24/11 更新, 對魚雷的傷害發揮作出調整, 亦會對 無畏艦船體 及 Griffin Navy Issue (獅鷲級海軍型) 作出調整。
- <fs small>(官網沒有寫明調整的數值, 那只好去 Sisi 挖一下了, 最終調整值請留意當日 patch note 爲準)</fs>
- 超大型魚雷的傷害, 爆炸速度, 飛行速度將會上調, 而其他魚雷則會有爆炸速度及飛行速度的上調, 爆炸半徑的下調。這將影響一系列相關艦船的表現, 例如 Phoenix (鳳凰級), Raven (烏鴉級), Typhoon (颱風級) 等。
- XL Torpedo (超大型魚雷):  *飛行速度 : +20%  *傷害 : +10%  *爆炸速度 : +20%
- Torpedo (魚雷), 其他型號 :  *爆炸半徑 : -10%  *爆炸速度 : +10%  *飛行速度 : +20%  *最大飛行時間 : +20%
