# 舰船译名纠错（SDE 权威）

全部 426 艘舰船的中英对照见 data/ship_names_full.md，检索时不需要它——SDE 卡片已逐艘收录正式译名。
本条目只保留**容易写错的那些**。

## 常见错写对照

文档里出现过、但与 SDE 不一致的写法。**检索与训练一律用右列**。

| 常见错写 | SDE 正确写法 | 英文名 |
|---|---|---|
| 戴莫斯级 | 戴默斯级 | Deimos |
| 拉克西斯级 | 拉克希斯级 | Lachesis |
| 厄洛巴斯级 | 俄洛巴斯级 | Erebus |
| 索提约 | 索迪约 | Sotiyo |
| 伊米卡斯 | 伊什塔级 | Ishtar |
| 巨鸟 | 猛禽级 | Raptor |
| 审判 | 审判者级 | Retribution |
| 地狱天使 | 地狱天使级 | Abaddon |
| 万王宝座 | 万王宝座级 | Megathron |
| 狞獾 | 狞獾级 | Caracal |
| 灾难 | 灾难级 | Apocalypse |
| 末日沙场（误作地狱天使） | 末日沙场级 | Armageddon |

> 注：中文语料里「灾难级」与「地狱天使级」被互换过多次，
> 两者分别是 Apocalypse 与 Abaddon，不可混用。

## 判据

- 船名、装备名一律以 SDE 的 trnTranslations 中文表为准
- 原文中的错写保留在 source.md（不改原文），但检索与训练以本表为准
