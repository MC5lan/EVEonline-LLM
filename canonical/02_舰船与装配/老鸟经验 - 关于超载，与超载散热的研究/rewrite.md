# 老鸟经验 - 关于超载，与超载散热的研究

一 单件装备超载 超载散热时，相邻一格装备受到24%伤害 相邻二格装备受到42.2%伤害 相邻三格装备受到56.1%伤害 相邻四格装备受到66.6%伤害 相邻五格装备 74.6%伤害 由此得出 超载第一定理： 单件装备超载时，离该装备槽位越远的装备受到的散热伤害越大 根据此定理，我们可以得出结论， 单件装备超载时，将该装备装配在最中间槽位， 可以使得整槽位受到的损伤最小

## 要点

- 二 多件装备超载 1， 两件装备超载 上面说到超载第一定理：单件超载时，越远的槽位受到的伤害越大 那么多件呢， 仅此先讲两件装备超载时 以乌鸦中槽ABCDEF 为例AB两个盾修时，CDEF受到的损伤如何呢？ 当A超载时C 受到42.2%伤害 F受到74.6%伤害 当再将B超载时，会发现C只受到24%伤害 F受到66.6%伤害 就这样，同时超俩件时，最远槽位受到的伤害反而降低了 这就是超载第二定理： 多件装备超载时，某一槽位受到的散热损害只与离他最近的超载装备为准，并不叠加散热伤害 好了，现在有个问题了，既然减少了，那散热伤害哪去了？ 给相邻的超载装备了！ B超载时C的伤害由42.2%变成24%，相应DEF也减少了，但是A装备这时受到的伤害就大了 AB此时相互受到的超载伤害是是其他槽位减少的散热伤害都加过来了 即[1-24%+(74.5%-66.6%)]=83.9% 比如单超A装备，可以超载4分钟，即240秒，如果再将B装备超载 那么A的超载时间会变成240秒/(1+83.9%)=130秒 以上大家可以实践，如果超载散热伤害，超载的装备会叠加，而不超载的装备会叠加， 就可以很容易得出结果，超载俩件或多件装备时，将其尽可能的远离 例如乌鸦ABCDEF， 需要同时超俩件时，将其分别放置在A F槽位超载，可以使得其余槽位受到的散热伤害最小 同时，A F槽位时超载装备时间最长 具体时间我不算了，反正比将俩装备相邻放时多超20多秒 同样，以乌鸦高槽6会战，剩下俩个被动或吸电装备时，高槽俩边各放三会战，中间放被动或其他装备 高槽会战架子超载的时间将延长十多秒。
