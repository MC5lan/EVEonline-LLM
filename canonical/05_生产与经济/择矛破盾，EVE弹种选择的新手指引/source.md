无人机与铁骑舰载机

无人机

无人机分为伤害无人机和电子战无人机

对使用A炮和混合炮的舰船来说，伤害无人机是对其单一伤害属性的补足，A炮舰船推荐携带动伤/爆伤的伤害无人机，而混合炮舰船则推荐携带电伤/爆伤的伤害无人机。

而对射弹炮、导弹和无人机为主要伤害手段的舰船来说，伤害无人机则是让其的伤害最大化，携带的一般是目标抗性最低属性的伤害无人机。

电子战无人机除了EC-300/600/900意外，其他类型收效甚微，一般不推荐携带；不过CCP得锉刀已经伸向了EC系列的无人机，仁者见仁智者见智吧~

散打篇

所有散打船都大致分为三种：自修型、速度抗型和有效抗型

护卫和驱逐船体

它们因为船体的限制导致防御槽位和电容量不够，一般都是单属性被动盾抗或者全属性被动甲抗，甚至没有抗性！

例1：retribution

它是典型的A族T2舰船抗性，热扛最低，因此推荐使用热伤的伤害类型进行打击：A炮和混合炮都有热伤属性，只需把握好距离切换弹药即可；射弹炮则推荐使用Republic Fleet Phased Plasma和Republic Fleet Depleted Uranium，Republic Fleet Depleted Uranium会更好，因为它的转速更高；导弹和无人机也选用热伤。

例2：Sabre

其最低的盾抗动热抗都是40%，不过动伤能更快的打穿其装甲（只有25%），所以首选动伤：混合炮的效果最好，A炮带热伤也还行；射弹炮推荐使用Republic Fleet Titanium Sabot，较远距离使用Republic Fleet Nuclear，无人机和导弹推荐动伤。

C族盾抗巡洋战巡即便加了单电抗，就算是T2船体它电抗属性依然是最低的，A炮就是个不错的选择，混合炮不推荐，射弹炮近距离用Republic Fleet EMP，较远距离使用Republic Fleet Proton；导弹和无人机用电伤。

M族T1盾抗船跟C族盾抗巡洋战巡一样，T2盾抗巡洋战巡和*例2 一样，不过射弹炮近距离推荐使用Republic Fleet Fusion。

例3：Vedmak

舰队战篇

这里将从船体的小到大例举一些例子给大家参考

例4：Harpy队

电抗最低，A炮是不错的选择，混合炮不推荐，射弹炮因为Harpy是高速目标，中近距离使用Republic Fleet Titanium Sabot，较远距离用Republic Fleet Proton。导弹无人机用电伤。

Jackdaw队的打法同Harpy队，这里不再重复

例5：GOKU队

GOKU队都是盾抗驱逐一下船体，特点是极低的信号半径和不错的速度，舰船的型号繁多，不过它们最低的抗性不是电抗就是热抗，A炮是个不错的选择（不过得想办法增加你炮台的转速，如氪药或者加装炮台转速脚本等），混合炮中磁轨炮不推荐，因为转速偏低，射弹炮中近距离推荐Republic Fleet Depleted Uranium，较远距离用Republic Fleet Proton；轻型/轻快导弹船最佳，用电/热伤导弹即可；无人机电/热伤自行选择补足。

例6：10AB Eagle队

Eagle队抗性最低的是电和爆，A炮是不错的选择，混合炮太不推荐，射弹炮近距离Republic Fleet EMP是首选，中距离比较吃力，没有合适的弹种，远距离用Tremor比较合适；导弹电/爆都可以但不推荐（你要么没有人家射程远，要么够射程的打出去的是人家抗性最高的两个伤害属性），无人机电/爆自行选择伤害补足。

例7：盾抗Muninn队

盾抗Muninn的动抗最低，爆抗次之，混合炮的磁轨炮武器平台打击效果不错，A炮不推荐；射弹炮近距离使用Republic Fleet Fusion，中距离使用Republic Fleet Titanium Sabot，远距离使用Tremor；导弹使用动伤，无人机也一样。

例9：Ferox和Hurricane队

Ferox和Hurricane电热抗最低，A炮能打出很好的效果，混合炮还凑合；射弹炮近距离使用Republic Fleet Phased Plasma，中距离用Republic Fleet Depleted Uranium，远距离有些纠结，可以考虑用Republic Fleet Proton；导弹用热伤，无人机电/热伤看情况补足。

PS-1：T1盾抗战巡队很怕隐形轰炸舰的投弹，运气好一轮可以团灭对方。

例10：Nightmare队

一般情况下Nightmare的动抗最低、热抗最高，A炮需要用动伤无人机补足，而磁轨炮需要用爆伤无人机；射弹炮近距离用Republic Fleet Fusion，中距离用Republic Fleet Titanium Sabot，远距离用Tremor，再补电伤无人机。导弹用动伤补爆伤无人机。

例11：Megathron和Bhaalgorn混编甲抗战列队

这两型战列配置都是爆抗最低、电抗次之，A炮需要补爆伤无人机，混合炮不推荐；射弹炮近距离用Republic Fleet Fusion，中距离略尴尬，远距离用Tremor，再补电伤无人机；导弹平台用爆伤补电伤无人机。
