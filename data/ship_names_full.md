## 常见错写对照

文档里出现过、但与 SDE 不一致的写法。**检索与训练一律用右列**。

|---|---|---|
| 戴莫斯级 | 戴默斯级 | Deimos |
| 拉克西斯级 | 拉克希斯级 | Lachesis |
| 厄洛巴斯级 | 俄洛巴斯级 | Erebus |
| 索提约 | 索迪约 | Sotiyo |
| 伊米卡斯 | 伊什塔级 | Ishtar |
| 巨鸟 | 猛禽级 | Raptor |
| 审判 | 审判者级 | Retribution |
| 地狱天使 | 地狱天使级 | Abaddon |
| 万王宝座 | 万王宝座级 | Megathron |
| 狞獾 | 狞獾级 | Caracal |
| 灾难 | 灾难级 | Apocalypse |
| 末日沙场（误作地狱天使） | 末日沙场级 | Armageddon |
